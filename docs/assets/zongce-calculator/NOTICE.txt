This directory and green-book/scholarship/zongce-calculator.md contain an
adaptation for 济南大学校园通. The upstream calculation rules, review-score
trimming, GPA weighting, table field aliases, and sample data are retained.
The source repository and license remain visible on the calculator page.
author-support.jpg is the original author's supplied support image, copied
without modification from the locally supplied zongce-calculator directory.

Changes made by 济南大学校园通:
- Replaced the standalone landing page with a native MkDocs tool page.
- Scoped CSS and event handlers and followed the main site's color scheme.
- Added accessible labels, inline validation and responsive layouts.
- Added strict numeric input checks and quoted CSV/TSV import handling.
- Preserved upstream import replacement behavior and mode-specific hints.
- Added lifecycle handling for Material instant navigation and cancelled
  stale file reads when the user edits, resets, or leaves the page.
- Kept all score calculations and file reading in the browser, without
  sending or persisting entered scores.

These notices apply to the calculator integration, not to the entire site
or the separately maintained pet administration repository.
