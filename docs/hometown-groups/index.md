# 🏘️ 老乡群

[← 返回校园生活](../campus-life/index.md){ .md-button .ujn-parent-return }

!!! info "📜 老乡群准则"
    1. **互助与分享**：鼓励分享家乡资讯、生活经验、求助信息，互帮互助，共叙乡情。
    2. **严禁商业行为**：禁止任何形式的商业广告、商品推销或带有盈利性质的信息，包括但不限于微商、代购、拼团销售等。
    3. **维护友善氛围**：禁止人身攻击、恶意谩骂、散布不实谣言、侵犯他人隐私等不当言行。
    4. **遵守法律法规**：严禁发布涉黄、涉赌、涉毒、暴力、诈骗等违法违规内容。
