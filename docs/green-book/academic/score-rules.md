# 📊 成绩规则

!!! info "📋 政策依据"

## 📝 考核方式

- 考核分**考试**和**考查**两类，可采用笔试、口试、实际操作、提交论文（报告）等方式进行
- 每学期的考试和考查课程均按培养方案规定执行

---

## 🔢 成绩记分方式

| 考核类型 | 记分方式 |
|----------|----------|
| 考试课程 | **百分制**（60 分为及格） |
| 考查课程、实验、实习、毕业论文（设计） | **五级制**（优秀/良好/中等/及格/不及格）或**五分制**（A/B/C/D/F） |

!!! tip "百分制快速换算"
    百分制成绩换算绩点公式：

    $$\text{绩点} = \text{成绩} \div 10 - 4.5$$

## 🏆 学分绩点与 GPA

### 单门课程学分绩点

$$\text{课程学分绩点} = \text{课程绩点} \times \text{课程学分}$$

### 平均学分绩点（GPA）

$$\text{GPA} = \frac{\sum(\text{课程绩点} \times \text{课程学分})}{\sum \text{课程学分}}$$

计算时四舍五入，精确到小数点后两位。

## ⚠️ 特殊规则

| 事项 | 规则 |
| ------ | ------ |
| **重修成绩** | 按最高成绩记载，不显示"重修"字样 |
| **成绩更正** | 新学期开学**两周内**向开课学院提出复核申请，逾期不再受理 |
| **作弊处理** | 该课程成绩记为无效，成绩系统记为零分，并给予相应纪律处分 |

## ❓ 常见问题

**Q：GPA 有什么用？**
A：GPA 是衡量学习质量的核心指标，与奖学金评定、推免保研、毕业学位等密切相关。

**Q：补考/重修的成绩怎么算？**
A：补考、重修获得的成绩会予以标注，但重修按最高成绩记载。

**Q：对成绩有异议怎么办？**
A：在新学期开学两周内向开课学院教务办提出成绩复核申请。
