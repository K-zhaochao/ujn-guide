# ✅ 免修 & 免听须知

!!! info "📋 政策依据"
    本页面内容依据《[济南大学本科学生学分制管理暂行规定](appendix/济南大学本科学生学分制管理暂行规定.md)》整理，详细条款请查阅原文。

---

## 📘 免修

### 申请条件

学生对培养方案规定的课程已经读过或通过自学等途径**确已掌握**，可以申请免修。

### 可免修课程范围

| 可以免修 | 不得免修 |
| ---------- | ---------- |
| 理论教学课程（专业课程需学院认定） | 思想政治理论课、形势与政策、体育课 |
| — | 军事理论与训练 |
| — | 实验环节、独立实验课、实习、毕业论文（设计） |
| — | 通识必修课程 |

### 申请流程

1. 在**确认选课结果前**填写《济南大学免修课程申请表》
2. 经学生所在学院与开课部门审核同意
3. 报教务处备案
4. 参加开课部门单独组织的**免修考试**，成绩合格者获得该课程学分

---

## 📗 免听

### 申请条件

学习成绩好、学习能力强的学生，经批准可以不跟班听课，免听课程的部分或全部内容。

### 申请流程

1. 在**新学期开学后两周内**填写《济南大学免听课程申请表》
2. 经任课教师所在学院审核同意后办理免听手续

### 免听后仍需完成的事项

- 完成课程的平时作业
- 完成平时测验
- 完成实践教学环节
- 跟班参加课程正常考核

成绩合格者获得该课程学分。

!!! warning "注意"
    **不得免修的课程同样不得免听。**

---

## 📋 免修 vs 免听 对比

| 对比项 | 免修 | 免听 |
| -------- | ------ | ------ |
| 申请时间 | 确认选课结果前 | 开学后两周内 |
| 是否参加考试 | 需参加免修考试 | 跟班参加正常考核 |
| 是否需要上课 | 不需要 | 不需要（但要完成作业和测验） |
| 适用范围 | 理论课程为主 | 学习能力强的学生 |

---

## ❓ 常见问题

**Q：免修考试难吗？**
A：免修考试由开课部门单独组织，难度与正常考试相当。建议对课程内容有充分把握再申请。

**Q：免听会影响平时分吗？**
A：免听后仍需完成平时作业和测验，这部分成绩会正常计入。
