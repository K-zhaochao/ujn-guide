# 💰 助学金须知

> 本页面内容依据《济南大学家庭经济困难学生资助管理办法》（济大校字〔2020〕90号）整理，如有变动以学校最新文件为准。

---

## 📋 概述

济南大学建立了以**家庭经济困难学生认定**为基础，以**国家助学金**为主体，辅以**学费减免**、**临时困难补助**和**校内勤工助学**等多种形式的资助体系，帮助家庭经济困难学生顺利完成学业。

## 🔍 家庭经济困难学生认定

### 申请基本条件

申请各项资助需同时满足以下条件：

1. 热爱社会主义祖国，拥护中国共产党的领导
2. 遵守宪法和法律，遵守学校规章制度
3. 诚实守信，道德品质优良
4. 勤奋学习，积极上进
5. 家庭经济困难，生活俭朴

### 不得认定的情形

有下列情况之一者**不得认定**为家庭经济困难学生：

- 隐瞒家庭经济实际情况、提供虚假信息的
- 由于家庭建房、购房、购车等原因造成家庭经济暂时困难的
- 有各种挥霍浪费、不合理消费等不良行为者
- 学年内因违反国家法律法规、校规校纪受到处分未解除者
- 延长修业年限者

### 认定档次

| 档次 | 适用情形 |
|------|----------|
| **特殊困难** | 建档立卡贫困家庭学生；城乡最低生活保障家庭学生；城乡特困供养学生；孤儿；烈士子女；家庭经济困难的残疾学生及残疾人子女；因重大自然灾害、突发意外、重大疾病等造成经济特别困难的 |
| **困难** | 父母务农或一方暂时失业，家庭成员有残疾或疾病且医疗费用负担较重；因自然灾害或突发事故财产损失较重；单亲且无经济收入或收入不足；其他原因造成困难 |
| **一般困难** | 基本生活费用低于当地最低生活保障标准或学校学生日常平均消费水平；父母务农无其他经济来源，有两名子女同时在接受非义务教育；其他原因造成一般困难 |

### 认定流程

认定工作**每年9月**进行一次，每年3月对全部家庭经济困难学生进行一次资格复查。如学生家庭经济状况发生显著变化，各单位应及时作出调整。

## 💵 国家助学金

### 资助标准

=== "本科生"

    国家助学金主要资助家庭经济困难学生的**生活费用开支**，平均资助标准为**每生每年3300元**，具体分为三档：

    | 档次 | 资助标准 |
    |------|----------|
    | 三档（最高） | **4400元/年** |
    | 二档 | **3300元/年** |
    | 一档（最低） | **2200元/年** |

    !!! note "重要说明"
        - 建档立卡学生原则上**最低享受国家二档助学金**
        - 免费师范生等已享受政策性生活补助的学生不再同时获得国家助学金
        - 获得国家助学金的学生可以**同时申请并获得**国家奖学金、国家励志奖学金、省政府励志奖学金中的一项

=== "研究生"

    研究生国家助学金**惠及全体学生**，每学年按十个月发放：

    | 层次 | 资助标准 |
    |------|----------|
    | 硕士研究生 | **600元/月** |
    | 博士研究生 | **1500元/月** |

### 评审流程

国家助学金**每学年评审一次**，实行等额评审。

![国家助学金评审发放工作流程](../../assets/images/资助管理流程图/附录3%20国家助学金评审发放工作流程.webp){ width="600" }

## 🎓 学费减免

### 全额减免

符合下列情况之一者，可以申请**全额减免**（年减免最高额度不超过8000元）：

- 家庭经济特别困难的**孤儿学生、残疾学生和烈士子女**
- **山东省户籍建档立卡**贫困学生

### 部分减免

符合下列情况之一者，可以申请**部分减免**：

- 享受民政部门低保资助家庭的子女、扶贫户的子女、优抚家庭子女、少数民族贫困家庭子女、城市特困职工家庭子女
- 父母有伤、亡、残、病丧失劳动能力无力支付全额学费的学生，因本人患病导致家庭经济特别困难的学生
- 因其他特殊原因造成经济特别困难的学生（如家庭遭受特大自然灾害等）

### 申请限制

有下列情况之一者**不得申请**学费减免：

- 上学年考试有不及格课程（一年级学生当学年考试有不及格课程）
- 当年享受过其它形式学费减免

### 评审时间

学费减免**每年4月和10月**各评定一次，由各单位负责组织实施。

## 🆘 临时困难补助

### 适用情形

有下列情况之一者，可以申请临时困难补助：

- 学生在校期间**患病住院治疗**的
- 学生发生**意外变故**而导致伤病等
- 其他未预见性原因，各单位研究后认为需要补助的

### 补助说明

- 临时困难补助为**临时性、一次性**补助金
- 补助金额由各单位视情况决定
- 各单位于年底前将本年度资助学生名单及发放金额报学生资助管理中心备案

## 🛠️ 校内勤工助学

### 岗位设置

勤工助学岗位以**公共服务部门**为主，兼顾校内教学助理、科研助理、行政管理助理等。

!!! warning "注意事项"
    - 不得让学生从事危险性、有害身心健康、不便于学生参与的工作
    - 不能占用学生上课、考试和实习等教学时间
    - 学生参加勤工助学的时间，原则上**每周不超过8小时，每月不超过40小时**

### 岗位类型

| 类型 | 说明 | 薪酬计算 |
|------|------|----------|
| **固定岗位** | 持续一个学期以上的长期性岗位和寒暑假期间的连续性岗位 | 一般按月计算 |
| **临时岗位** | 不具有长期性，通过一次或几次勤工助学活动即完成任务的岗位 | 一般按次计算 |

### 申请流程

- 固定岗位需在每学年指定时间由用人单位向学生资助管理中心提出设岗申请
- 临时岗位需**提前2天**向学生资助管理中心提出设岗申请
- 学校学生资助管理中心统一负责学校勤工助学工作的组织和管理

## 📌 其他说明

### 生源地信用助学贷款

生源地信用助学贷款有关事项按照上级文件执行。

### 新生入学绿色通道

家庭经济困难的新生，在提交相关证明后，可**缓交全部或部分学费**，通过"新生入学绿色通道"办理入学手续。

### 申诉渠道

如对各类资助评选结果有异议，可在**公示期内**通过公示中提供的渠道向有关部门进行申诉。
