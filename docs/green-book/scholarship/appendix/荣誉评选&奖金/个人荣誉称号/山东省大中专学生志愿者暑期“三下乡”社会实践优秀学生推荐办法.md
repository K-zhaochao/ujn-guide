# 山东省大中专学生志愿者暑期“三下乡”社会实践优秀学生推荐办法

## 一、推荐条件

1. 全程参与实践团队实践活动，在实践团队中公认度较高。
2. 获得本年度济南大学社会实践优秀学生称号。

## 二、推荐名额

根据上级组织分配名额而定。

## 三、推荐时间

每年9月份推荐。

## 四、推荐程序

1. 校团委按照当年团省委分配给学校省级社会实践优秀学生名额，参照组队数量、参与人数和实践效果，分配到各组织单位。
2. 各组织单位在上述推选条件的基础上，自行规定相关评选细则和办法，对照各团队成员申报材料进行评定、选拔。
3. 各组织单位将申报材料报校团委审核，并进行公示。公示无异议后，由校团委统一报送团省委审批。
