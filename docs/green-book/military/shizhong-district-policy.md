# 🎖️ 济南市市中区应征入伍其他优抚政策

（各项优抚政策以国家或应征地当年具体政策为准）

---

## 一、优先优待

### 1. 优先落户济南

从济南应征的非济南籍大学毕业生，定兵后凭《入伍通知书》《毕业证》"零门槛"入伍地区（县）退役军人事务局集体户，退役后享受济南安置政策。

!!! tip "适用对象"
    从济南市入伍的毕业生

### 2. 出行优待

**① 免费乘坐城市公共交通工具**

自2020年10月1日起，济南市城乡交通运输局对济南市户籍的退役军人发行"拥军卡"，免费乘坐城市公共交通工具。在有效期内可免费乘坐济南市行政区域内常规城市公交、地铁线路。

**② 免费游览公园景点**

自2020年10月1日起，退役军人持"泉城拥军交通卡"（简称"拥军卡"）或其他有效证件可免费进入济南天下第一泉风景区服务中心、济南市园林和林业绿化局属各公园（景区）游览（免费游园范围不含园中其他需另行购票的游览项目）。

!!! tip "适用对象"
    落户济南的毕业生、济南市户籍的退役军人

---

## 二、复学升学

### 3. 单列指标推荐优秀学生、优秀学生干部

高校可在正常推荐指标外，单列指标面向退役复学学生推荐山东省普通高等学校优秀学生和优秀学生干部，推荐人数不超过学校正常指标的 **10%**。

!!! tip "适用对象"
    在校生、高校新生

### 4. 优先培养入党

高校党组织在确定入党积极分子和接收预备党员时，要将学生报名参军和应征入伍、报效祖国的思想政治表现纳入考评体系中；在研究退役复学学生入党申请时，符合《中国共产党章程》中规定的党员条件标准的，可优先培养入党。

!!! tip "适用对象"
    在校生、高校新生

---

## 三、经济待遇

（以济南市市中区为例，其他以应征地政策为准）

### 5. 家庭优待

入伍大学生按规定享受优待政策，优待金由批准入伍地发放，其家庭享受军属待遇，由户籍所在地负责落实相关优待。

**① 义务兵家庭优待金**

义务兵服役期间发放家庭优待金（济南市市中区2021年家庭优待金标准为 **37378元/人/年**，每年分2次发放，一般在4月份和11月份）。

**② 增发艰苦地区家庭优待金**

对到西藏、新疆等高原艰苦地区服役的，按照当地义务兵家庭优待金标准的 **2倍** 发放优待金（以济南市市中区为例：2021年标准为 **74756元/人/年**）。

!!! tip "适用对象"
    毕业生、在校生、高校新生

### 6. 参军入伍其他经济待遇

**① 一次性应征补助金**

对户籍在外地或在外地就学的大学毕业生，从我市应征入伍的，凭《入伍通知书》，发放一次性食宿、交通应征补助金：

| 来源 | 补助标准 |
|------|----------|
| 省外 | **800 元** |
| 省内 | **500 元** |

!!! tip "适用对象"
    返乡、返校在济南市市中区应征报名的毕业大学生

**② 大学毕业生士兵立功奖励金**

山东现役军人立功奖励现行标准为省、市、县级党委、政府分别对当年授予个人荣誉称号和荣立一、二、三等功的现役军人家庭开展普遍走访慰问活动，并各发放慰问金：

| 等级 | 慰问金标准 |
|------|-----------|
| 个人荣誉称号 | **20000 元** |
| 一等功 | **10000 元** |
| 二等功 | **5000 元** |
| 三等功 | **2000 元** |

凡从济南市入伍的大学毕业生发放为部队贡献奖励金：

- 在部队提干、考入军校的：奖励 **2000元**（税后）
- 荣立"三等功"以上奖励的：在当地原有奖励基础上再增加 **1000元**（税后）

!!! tip "适用对象"
    从济南市入伍的新生、在校生、毕业生，现役军人

**③ 退役金**

对自主就业的退役士兵，由部队发给一次性退役金（目前标准为 **4500元/年**），原济南户籍学生另有一次性就业补助。

!!! tip "适用对象"
    自主就业退役士兵
