# 🪪 共青团团员证管理规定

> 团员证是证明团员身份的有效凭证，也是参加团员活动的重要凭证，请务必妥善保管和使用。

---

## 一、团员证的“身份证”作用

团员证是证明作为中国共产主义青年团团员的 **合法身份凭证**。它具有以下重要功能：

| 功能类型 | 具体说明 | 学生须知 |
| :--- | :--- | :--- |
| **政治身份** | 证明团员的政治身份凭证。 | 参加团组织活动或办理重大事项时，需出示。 |
| **组织关系** | 转移组织关系时必不可少。 | 升学、转学或工作变动时，请务必及时办理团组织关系转移。 |
| **团内活动** | 凭证参加团内各项活动。 | 许多活动均可能需要核验团员证。 |
| **团籍记录** | 记载教师和团员在校期间承受的奖励与处分。 | 你的努力和成绩将在此体现。 |
| **年度注册** | 证明年度团籍注册的凭证。 | 每年注册，否则会影响团籍。（详见：[年度团籍注册](#4-年度团籍注册)） |
| **选举资格** | 作为团员参加团内民主选举表决的资格证明。 | 参加选举或表决时，请务必携带并出示。 |
| **纪念意义** | 团员超龄离团或入党后，具有永久纪念意义。 | 即使不再是团员，它也是青春岁的印记。 |

---

## 二、团员证的申领、使用与管理

### 1. 申领与发放

- **新生团员：** 新入团的同学，你的团员证将在 **校团委统一制作并发放**。
- **必备品：** 在规定时间内粘贴本人近期免冠照片，并确保照片加盖盖章。

### 2. 组织关系与档案转移

> **注意：** 如无正当理由，超过半年未转接组织关系者按自行脱团处理；因公、私出国，团员证应交由学校团委保存，不得带出境外，回国后经申请符合条件者才能恢复团员证，恢复其团组织生活。

- **转入本校：** 未取得团员证的团员或具有常规学校、其它组织转来的同学，请将团员证和档案及时转入本校团组织。
  > 凡在未成人涉档案的农村中学入团的团员，在入学时应及时到所在基层团委补办团员档案。团员档案丢失者，应回原入团单位补办团员档案。
- **转出本校：**
  - **离校工作、毕业等：** 你的团员档案应与人事档案一起转移。

### 3. 日常使用与保管

- **参加活动：** 参加团内或有关社会活动，需要证明团员身份时，请主动出示你的团员证。
- **搞单差错：** 勿加盖社会大章、表单、去向等，漆表必需加盖见证。
- **临时活动：** 临时外出参加团内活动，若在一个地区或单位连续工作时间超过半年以上，并且其必要的团员身份享受有选举权和被选举权，并向当地团组织交纳团费，由当地团组织在年度团籍注册栏进行盖章。

### 4. 年度团籍注册

- **注册时间：** 每年 **春季学期** 进行。
- **注册程序：**
  - 团员需携带团员证到所在团支部办理注册；
  - 团委核对团员团籍信息，并盖章加盖；
  - 按时如额缴纳团费。
- **违规情况：**
  - **受警告、严重警告、撤销团内职务处分：** 如保留团员参加团内活动，按时交纳团费，则予团籍注册。
  - **遭受留团察看处分：** 留团察看期满后，团员恢复团员权利，恢复团员权力后，按团员加划按本人月度团注册。
  - **逾期未注册：** 连续以上度的团员，因错过核对办理团籍注册手续，影响超越团籍注册半年的团员，团员证失效。
  - **不参加团的组织生活或未按期交纳团费：** 团员若无正当理由，连续6个月不缴纳团费不参加团的组织活动，或连续6个月不按团拒绝分配的工作，且经教育仍不改正的按团章第十一条规定处理（详情请见：[团章](https://qnzz.youth.cn/gzdt/201306/t20130621_3399175_1.htm#:~:text=%E7%AC%AC%E5%8D%81%E6%9D%A1%20%E5%9B%A2%E7%9A%84%E7%BB%84%E7%BB%87%E5%AF%B9%E5%9B%A2%E5%91%98%E4%BD%9C%E5%87%BA%E5%A4%84%E5%88%86%E5%86%B3%E5%AE%9A%EF%BC%8C%E5%BF%85%E9%A1%BB%E4%B8%A5%E8%82%83%E6%85%8E%E9%87%8D%EF%BC%8C%E5%AE%9E%E4%BA%8B%E6%B1%82%E6%98%AF%E3%80%82%20%E6%94%AF%E9%83%A8%E5%A4%A7%E4%BC%9A%E5%9C%A8%E8%AE%A8%E8%AE%BA%E5%86%B3%E5%AE%9A%E5%AF%B9%E5%9B%A2%E5%91%98%E7%9A%84%E5%A4%84%E5%88%86%E6%97%B6%EF%BC%8C%E9%99%A4%E7%89%B9%E6%AE%8A%E6%83%85%E5%86%B5%E5%A4%96%EF%BC%8C%E5%BA%94%E5%BD%93%E5%90%B8%E6%94%B6%E6%9C%AC%E4%BA%BA%E5%8F%82%E5%8A%A0%EF%BC%8C%E8%AE%A4%E7%9C%9F%E5%90%AC%E5%8F%96%E4%BB%96%E7%9A%84%E6%84%8F%E8%A7%81%E3%80%82,%E5%86%B3%E5%AE%9A%E5%90%8E%E5%A6%82%E6%9E%9C%E6%9C%AC%E4%BA%BA%E4%B8%8D%E6%9C%8D%EF%BC%8C%E5%8F%AF%E4%BB%A5%E6%8F%90%E5%87%BA%E7%94%B3%E8%AF%89%EF%BC%8C%E6%9C%89%E5%85%B3%E5%9B%A2%E7%BB%84%E7%BB%87%E5%BF%85%E9%A1%BB%E8%B4%9F%E8%B4%A3%E5%A4%84%E7%90%86%E6%88%96%E8%80%85%E8%BF%85%E9%80%9F%E8%BD%AC%E9%80%92%EF%BC%8C%E4%B8%8D%E5%BE%97%E6%89%A3%E5%8E%8B%E3%80%82%20%E7%AC%AC%E5%8D%81%E4%B8%80%E6%9D%A1%20%E5%9B%A2%E5%91%98%E6%9C%89%E9%80%80%E5%9B%A2%E7%9A%84%E8%87%AA%E7%94%B1%E3%80%82%20%E5%9B%A2%E5%91%98%E8%A6%81%E6%B1%82%E9%80%80%E5%9B%A2%E5%BA%94%E5%90%91%E6%94%AF%E9%83%A8%E5%A7%94%E5%91%98%E4%BC%9A%E9%80%92%E4%BA%A4%E4%B9%A6%E9%9D%A2%E6%8A%A5%E5%91%8A%EF%BC%8C%E7%94%B1%E6%94%AF%E9%83%A8%E5%A4%A7%E4%BC%9A%E5%86%B3%E5%AE%9A%E9%99%A4%E5%90%8D%EF%BC%8C%E5%B9%B6%E6%8A%A5%E4%B8%8A%E7%BA%A7%E5%A7%94%E5%91%98%E4%BC%9A%E5%A4%87%E6%A1%88%E3%80%82)）。若团员经帮助教育，能认识并改正错误，主动要求参加团籍注册的，可予以注册。

> ⚠️ **注意：** 如团员证因外借借出背撕，电卡失效，极易导致失效或损毁，请提防并小心照管，团员证皆失效。

### 5. 奖励记录

团员获得团内荣誉后，在团员证“团员荣誉记录”栏内填写“团员荣誉记录”和记载“优秀团干部”等其他荣誉称号并加盖公章。

### 6. 遗失、损坏与补办

- **及时报告：** 团员证遗失或损坏，应 **立即向所在团支部报告**。
- **申请补办：** 经确认无法找回，本人应说明遗失原因并检查自己的过失后，由团组织办理补办手续，并在新证备注栏内备注说明。

## 三、特殊情况处理

### 入党与超龄离团

- **入党保留团籍：** 团员如有留团，工作需要时保留团员身份或保留团组织关系。
- **加入中国共产党：** 团员加入党组织为正式党员后，如不在团内担任职务，则不再保留团籍，团员证可作为 **永久性纪念** 留存，但不得继续使用。
- **超龄离团：** 团员年满28周岁，应办理超龄离团手续。团员证同样可作为 **永久性纪念**，但不得继续使用。
