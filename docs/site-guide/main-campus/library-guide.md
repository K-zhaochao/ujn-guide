# 📚 新生入馆指南

## 入馆相关规范

- **开放时间**：周一至周日 7:00-22:00，周二 12:00-16:00 闭馆
- **入馆凭证**：本校师生刷校园一卡通，校外人员登记有效证件入馆
- **行为禁令**：
  - 保持安静，电子设备静音、禁止外放
  - 禁止私带未办借阅手续图书离馆
  - 爱护书刊、设施，禁止涂画、挪动桌椅
  - 严禁私发广告、吸烟用火、携带易燃易爆物品、外卖入馆

## 座位与储物柜

- 座位需**线上预约**，按时入座、禁止占座
- 违规将限制预约、入馆甚至通报学院
- 在校学生仅可预约 1 个储物柜，禁止调换、转卖

## 馆舍布局

设有**主校区综合馆**、**舜耕校区商科特色馆**两处馆舍，总建筑面积约 6 万平方米，阅览座位 8000 个。

## 馆藏资源

| 资源类型 | 说明 |
|----------|------|
| 纸质资源 | 两校区阅览室、书库 |
| 电子资源 | 图书馆官网数字数据库 |

- 校园网内直接访问，校外可通过 **VPN** 登录查阅
- 拥有上百种中外数据库，馆内不定期开展数据库培训

## 图书借还服务

- **自助借还机**：多楼层配备，两校区设有 24 小时自助还书机
- **电子图书借阅机**：主校区二楼配备，手机扫码即可借阅
- **借阅规则**：
  - 每人最多借 **20 册**
  - 借期 **90 天**（本科生、教职工、研究生）
  - 可续借 **1 次**、预约 **2 册**
  - 超期图书无法再次借阅
  - 假期图书归还日期系统自动顺延
  - 图书遗失或损坏需购同款图书抵赔

## 线上系统

登录图书馆官网「**我的图书馆**」（账号：校园卡号，初始密码：身份证后六位），可查询借阅记录、办理续借、预约、荐购等业务。

| 服务 | 说明 |
