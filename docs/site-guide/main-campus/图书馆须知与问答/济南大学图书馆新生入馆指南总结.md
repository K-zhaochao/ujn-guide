# 济南大学图书馆新生入馆指南总结

## 一、入馆相关规范

1. 开放时间：周一至周日7:00-22:00，周二12:00-16:00闭馆；节假日正常开放，寒暑假开放时间另行通知。
2. 入馆凭证：本校师生刷校园一卡通，校外人员登记有效证件入馆。
3. 行为禁令：保持安静，电子设备静音、禁止外放；不可私带未办借阅手续图书离馆；爱护书刊、设施，禁止涂画、挪动桌椅；严禁私发广告、吸烟用火、携带易燃易爆物品、外卖入馆；规范安全用电。
4. 座位与储物柜：座位需线上预约，按时入座、禁止占座，违规将限制预约、入馆甚至通报学院；在校学生仅可预约1个储物柜，禁止调换、转卖，违规取消使用权。
5. 咨询渠道：主校区二楼215室、舜耕校区109室现场咨询，可拨打对应电话或发送指定邮箱咨询各类问题。

## 二、馆舍布局

设有主校区综合馆、舜耕校区商科特色馆两处馆舍，总建筑面积约6万平方米，阅览座位8000个。

## 三、馆藏资源

1. 资源类型：分为纸质资源（两校区阅览室、书库）与电子资源（图书馆官网数字数据库）。校园网内直接访问，校外可通过VPN登录查阅。
2. 数字资源：拥有上百种中外数据库，馆内不定期开展数据库培训，使用问题可咨询信息服务中心。

## 四、图书借还服务

1. 设备渠道：多楼层配备自助借还机，两校区设有24小时自助还书机；主校区二楼配备电子图书借阅机，手机扫码即可借阅电子书。
2. 借阅规则：每人最多借20册，本科生、教职工、研究生借期90天；可续借1次、预约2册，超期图书无法再次借阅；假期图书归还日期系统自动顺延；图书遗失或损坏需购同款图书抵赔，无法购置则按出版年限赔偿。
3. 线上系统：登录图书馆官网“我的图书馆”（账号校园卡号，初始密码身份证后六位），可查询借阅记录、办理续借、预约、荐购等业务。
4. 业务办理：超期、丢书、挂失、休学复学等业务统一在读者服务中心办理。

## 五、配套服务

1. 网络：馆内全域覆盖Wi-Fi；公共检索机、电子阅览室刷卡免费使用，禁止占机自习。
2. 空间预约：座位、研讨室可通过预约网站、馆内触摸屏、专用APP、微信公众号四种渠道预约。
3. 文印服务：两校区均部署自助文印机，凭校园卡完成打印、复印、扫描，收费标准以设备提示为准。

## 六、通知渠道

图书馆官网、服务邮箱、大厅大屏、官方微博、微信公众号同步发布各类通知公告。
