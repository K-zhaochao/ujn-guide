## ❓ Q1: 校园卡丢了怎么办？ <a id="q1"></a>

别担心！校园卡丢失后，请立即按以下步骤操作：

### 1. 🚶 挂失卡片

为了您的财产安全，请第一时间进行挂失：

* **a) 手机微信端：**
  进入 **智慧济大** -> **微校园** -> **我的** -> **我的校园卡** -> 选择 **挂失解挂** （🌟 **强烈推荐使用！** 最便捷的方式）。

* **b) 电脑端：**
  登录 **智慧济大** 门户网站 -> **我的信息** -> **一卡通** -> 选择 **挂失卡片**

* **c) 自助电话挂失：**
  拨打以下电话号码进行自助挂失：
  * (0531) 89736003
  * (0531) 89736004

* **d) ⚠️ 重要提示：**
  在"卡博士"小程序进行的挂失操作是**无效**的，请务必通过上述官方渠道挂失！

### 2. 🛠️ 补办新卡

挂失完成后，您可以前往校园卡业务部办理新卡：

* **a) 补办时间：**
  挂失满**24小时后**，即可前往校园卡业务部办理补办手续。

* **b) 工本费用：**
  工本费为**10元**，支持微信或支付宝扫码支付 💳 💰。

* **c) 办理凭证：**
  * **本人补卡：** 无需携带任何证明。
  * **代他人补卡：** 需携带被代办人的**有效证件**。

### 3. 💡 温馨提醒

* **a) 失而复得怎么办？**
  如果丢失的卡片后来找回了，你需要进行**解挂**操作。解挂流程与挂失卡片的路径相同。

* **b) 默认密码：**
  校园卡默认密码为您校园卡号的**后6位**数字，请务必妥善保管和记忆您的卡号及密码。

## ❓ Q2: 校园卡如何充值？ <a id="q2"></a>

为确保您的校园卡金额充足，你可以选择以下充值方式：

### 1. 💳 线上充值（支付宝）

* 通过支付宝 **校园一卡通** 小程序进行充值：
  * 搜索并进入"校园一卡通"小程序。
  * 选择"济南大学"。
  * 正确输入你的姓名及卡号。
  * 输入你希望充值的金额。
  * 点击"提交"即可完成线上充值。

### 2. 🏧 线下圈存

线上充值完成后，需进行线下圈存，将线上金额转入校园卡：

* **a) 圈存时间：**
  支付宝充值满**5分钟后**，即可前往支付宝自助圈存机进行圈存操作。

* **b) 📍 主校区支付宝自助圈存机位置：**
  * 一食堂
  * 二食堂
  * 三食堂
  * 八食堂
  * 九食堂
  * 校医院
  * 图书馆
