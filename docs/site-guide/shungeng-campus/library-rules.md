# 📖 图书阅览室规则

## 服务对象与阅览模式

面向全校师生**开架阅览**，读者可自由进出各阅览室查阅文献。

## 图书使用规范

- 可通过阅览室查询系统找书，保持书架整齐
- 图书可跨阅览室阅览，阅后归至指定位置
- 借还图书使用自助设备办理

## 座位管理要求

- 需**预约座位**、按时入座，离馆带走个人物品
- 严禁占座：占座物品会统一收缴，凭校园卡登记领取
- 违规将被限制预约、入馆甚至通报学院

## 设施与图书保护

- 爱护书刊、馆内设施，不得涂画损坏设备
- 禁止私自挪动、私自带桌椅就座

## 环境秩序要求

- 保持安静，禁止交谈、接打电话
- 杜绝吸烟、吃零食、吐痰、乱扔垃圾等不文明行为

## 违规处理

- 违规人员会被工作人员提醒批评并依规处置
- 拒不配合者按校及图书馆规定从严处理
