# 济南大学图书馆2024版读者入馆须知总结

1. 入馆凭证：本校学生刷校园一卡通；校外人员需在图书馆公众号完成访客预约后扫码入馆，全体读者需服从馆内管理。
2. 环境秩序规范：保持安静，电子设备调静音，禁止喧哗、朗读、阅览室内接打电话；着装整洁文明。
3. 财物设施保护：不得涂改、撕毁图书，禁止刻画、损坏馆内设备、私自挪动桌椅。
4. 图书借阅规定：图书需通过自助设备完成借还，未办手续不得带出，检测仪报警时配合核查。
5. 禁带及禁止行为：馆内禁止吸烟、用火、违规用电；严禁携带易燃易爆品、马扎、收纳箱、外卖进入；未经许可不可张贴、发放广告宣传品。
6. 座位管理：使用预约系统提前预约、按时入座，离馆带走私人物品，禁止占座，违规将限制预约、入馆或通报学院。
7. 储物柜规则：在校读者凭校园卡仅可预约1个储物柜，禁止私下调换、转租，违者取消使用权。
8. 咨询渠道：主校区二楼215室、舜耕校区109室现场咨询，也可拨打对应办公电话或发送指定邮箱咨询问题。
