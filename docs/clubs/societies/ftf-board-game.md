# 🎲 FTF 桌游社 <img src="../../../assets/images/社团与组织/社团/济南大学FTF桌游社徽章.webp" alt="FTF桌游社徽章" width="48" style="vertical-align:middle; margin-left:8px;">

## 简介

FTF 桌游社围绕丰富校园文化、提升社员社交与思维能力开展活动。

## 日常活动

- **经典桌游体验**：三国杀、剧本推理、兵棋、TCG、德式美式等桌游
- **定期赛事**：定期举办赛事，赋以丰厚奖励，吸引新老社员积极参与
- **轻松氛围**：营造轻松愉悦的交流氛围

!!! tip "新手友好"
    无需害怕不熟悉桌游规则，每场活动都有老手耐心讲规，欢迎对桌游感兴趣的朋友前来体验！
