# 宠物投稿审核与互动说明

## 已通过投稿的修改

已通过的投稿被修改后，当前公开内容会继续保留在宠物收集录中。新的内容会作为候选修改进入审核，不会提前展示。审核通过后，候选内容才会替换公开版本；未通过、撤回或已过期的候选内容不会影响当前公开稿。

投稿者提交公开稿修改后，“我的投稿”会自动切换到“待审核”。这里的待审核同时包含首次投稿和已公开内容的候选修改；候选修改的记录会标注“修改待审核（当前公开）”，避免误以为图鉴已下线。

后台“待审核”页会把普通新投稿和“公开稿修改”分开显示。修改卡片先展示各字段的公开值与候选值；打开审核页后可并排查看完整字段和全部照片顺序，再逐条通过或拒绝。公开稿修改不能和普通新投稿一起批量处理。

若公开稿修改未通过，“我的投稿”会在该记录内醒目展示审核意见和“按意见重新修改”入口。该入口会载入被拒候选内容供继续修订，保存后创建新的待审核修改；被拒记录保留为审核历史。撤回只适用于仍在待审核中的修改，已拒绝的修改不需要撤回。

## 互动通知

他人点赞或取消点赞时，投稿者会在导航栏的通知按钮看到对应记录。通知中的用户名会使用后台配置的主页链接；没有可用主页链接或已注销的账号会以普通文字显示。

“我的投稿”的历史只记录投稿提交、编辑、审核、删除和修订等生命周期事件，不包含点赞或取消点赞记录。
