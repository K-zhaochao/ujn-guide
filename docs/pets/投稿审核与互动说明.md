# 宠物投稿审核与互动说明

## 个人工作区

登录后，账号信息、通知、管理后台入口和退出操作会保留在页面顶部；紧接其下的个人工作区默认打开“我的投稿”。“我的投稿”和“我的收藏”通过同一组页签切换，不再需要分别点击导航按钮展开或收起。

投稿入口在工作区中只保留一个。未进入“我的收藏”前不会请求收藏列表；切换到该页签后才按点赞时间加载仍公开的记录。收藏页可按名称、地点、描述、动态字段或投稿 ID 搜索，也可按收藏日期范围筛选；日期以北京时间自然日计算，结束日期包含当天。退出登录后，整个个人工作区会随账号栏一起隐藏。

账号栏中的箭头按钮可收起或重新展开个人工作区；按钮会在“向上”和“向下”箭头之间切换，并同步更新无障碍标签。收起时不会退出账号、清空筛选条件或影响审核中的投稿。每次重新登录仍默认展开，避免遗漏待审核状态或投稿入口。

手机端会把两个页签排成等宽的一行，投稿入口独占下一行；账号、通知和退出操作保持在上方，不会与筛选项或投稿操作相互挤压。该布局的颜色和边框使用 Material 的主题变量，会随浅色和 slate 深色主题同步变化；投稿卡片的状态标签在深色主题使用不透明底色，避免封面图片干扰“已通过”“已拒绝”等文字的阅读。

## 已通过投稿的修改

已通过的投稿被修改后，当前公开内容会继续保留在宠物收集录中。新的内容会作为候选修改进入审核，不会提前展示。审核通过后，候选内容才会替换公开版本；未通过、撤回或已过期的候选内容不会影响当前公开稿。

投稿者提交公开稿修改后，“我的投稿”会自动切换到“待审核”。这里的待审核同时包含首次投稿和已公开内容的候选修改；候选修改的记录会标注“修改待审核（当前公开）”，避免误以为图鉴已下线。

后台“待审核”页会把普通新投稿和“公开稿修改”分开显示。修改卡片先展示各字段的公开值与候选值；打开审核页后可并排查看完整字段和全部照片顺序，再逐条通过或拒绝。公开稿修改不能和普通新投稿一起批量处理。

若公开稿修改未通过，“我的投稿”会在该记录内醒目展示审核意见，并提供“按意见重新修改”和“撤回修改”入口。前者会载入被拒候选内容供继续修订，保存后创建新的待审核修改；后者可用于待审核或被拒绝的本人候选稿，将其标记为“已撤回”。被拒和已撤回记录均保留为审核历史，且不会影响当前公开内容。

投稿列表和编辑弹窗会在手机端自动改为单列布局：筛选项、操作按钮、长审核意见和动态字段均可换行显示，不会挤压或遮挡内容。

## 搜索

宠物收集录列表页的搜索框支持按宠物名、地点或投稿 ID 查找。投稿 ID 支持三种写法：完整 ID（`pet_xxx`）、短 ID（`xxx`，自动补 `pet_` 前缀）以及带 `#` 前缀的短 ID（`#xxx`）；输入 ID 时会精确匹配该投稿，输入其他关键词时仍按名称、地点、外观、性格和描述模糊匹配。

“我的投稿”的搜索框同样支持按名称、地点、描述或投稿 ID 查找，方便在大量投稿中快速定位某一条记录。

“我的收藏”使用相同的关键词规则，并额外提供收藏日期范围筛选；筛选条件影响完整收藏结果和分页，而不仅是当前页。

## 互动通知

他人点赞或取消点赞时，投稿者会在导航栏的通知按钮看到对应记录。通知中的用户名会使用后台配置的主页链接；没有可用主页链接或已注销的账号会以普通文字显示。

“我的投稿”的历史只记录投稿提交、编辑、审核、删除和修订等生命周期事件，不包含点赞或取消点赞记录。
