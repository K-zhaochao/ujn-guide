# 🧰 实用工具

给济大同学做的小工具，都能直接在浏览器里用，不需要安装任何东西：

<div class="grid cards" markdown>

- :material-calculator-variant-outline: **综测计算器**

    ---
    填入绩点与综合素质成绩，实时算综测。支持表格导入，**成绩只在你的浏览器里计算**，不上传。

    [:octicons-arrow-right-24: 开始计算](../green-book/scholarship/zongce-calculator.md)

- :material-file-excel-outline: **教务成绩导出**

    ---
    在教务系统里一键把本人成绩导出成 Excel（.xls），省掉一页页抄的功夫。在你**已经登录**的浏览器里运行。

    [:octicons-arrow-right-24: 使用说明](grade-export.md)

</div>

!!! warning "先看这段再用"
    - 这些工具都在**你自己的浏览器/电脑上**运行。本站**不接触、不收集、不存储**你的任何账号、密码或成绩数据；
    - 只用于**本人的账号与本人的数据**，请遵守学校的信息系统使用规定，不要高频请求、不要用于批量抓取；
    - 工具按「现状」提供，我会尽量写清楚它的行为，但你仍需自行核对结果是否符合预期。
