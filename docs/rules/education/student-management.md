# 🏫 学生管理规定

!!! info "📋 原始文件"
    本页面内容基于《济南大学学生管理规定》（济大校字〔2025〕42号）整理，详见 [原文](../appendix/教育管理规定/济南大学学生管理规定.md)。

## 总则

- 依据《教育法》、《高等教育法》、《普通高等学校学生管理规定》（教育部令第41号）制定
- 适用于济南大学接受普通高等学历教育的研究生和本科生

## 学生权利

| 权利 | 说明 |
| ------ | ------ |
| 参加教育教学活动 | 参加学校教育教学计划安排的各项活动，使用学校提供的教育教学资源 |
| 参加社会实践 | 参加社会实践、志愿服务、勤工助学、文体体育及科技创新等活动 |
| 申请奖助学金 | 申请奖学金、助学金及助学贷款 |
| 获得公正评价 | 在思想品德、学业成绩等方面获得科学、公正评价 |
| 参与学校管理 | 以适当方式参与学校管理，享有知情权、参与权、表达权和监督权 |
| 提出申诉 | 对学校给予的处理或处分有异议，可向学校、教育行政部门提出申诉 |

## 学生义务

| 义务 | 说明 |
| ------ | ------ |
| 遵守法律法规 | 遵守宪法和法律、法规 |
| 遵守学校规章 | 遵守学校章程和规章制度 |
| 恪守学术道德 | 恪守学术道德，完成规定学业 |
| 缴纳学费 | 按规定缴纳学费及有关费用 |
| 遵守行为规范 | 遵守学生行为规范，尊敬师长，养成良好的思想品德和行为习惯 |

## 学籍管理

### 入学与注册

- 新生持录取通知书，按学校要求和规定期限到校办理入学手续
- 因故不能按期入学的，应当向学校请假
- 未请假或请假逾期的，除不可抗力等正当事由外，视为放弃入学资格
- 学校在报到时对新生入学资格进行初步审查
- 入学后 3 个月内按照国家招生规定进行复查

### 考核与成绩记载

- 学生应当参加学校教育教学计划规定的课程和各种教育教学环节的考核
- 考核成绩记入成绩册，并归入学籍档案
- 思想品德考核以个人小结、师生民主评议等形式进行
- 体育成绩评定要突出过程管理

### 转专业与转学

- 学生在学习期间对其他专业有兴趣和专长，符合学校相关规定的，可以申请转专业
- 以特殊招生形式录取的学生，国家有相关规定或录取前与学校有明确约定的，不得转学

### 休学与复学

- 学生可以分阶段完成学业，应当在学校规定的最长学习年限内完成学业
- 学生申请休学或学校认为应当休学的，经学校批准，可以休学
- 休学学生应当办理手续离校，学校为其保留学籍
- 休学期满前应当在学校规定期限内提出复学申请

### 退学

以下情况学校可予退学处理：

- 学业成绩未达到学校要求或在规定学习年限内未完成学业
- 休学、保留学籍期满未提出复学申请或复查不合格
- 患有疾病或意外伤残不能继续在校学习
- 未经批准连续两周未参加学校规定的教学活动
- 超过规定期限未注册且未履行暂缓注册手续

### 毕业与结业

- 修完教育教学计划规定内容，成绩合格，达到毕业要求的，准予毕业
- 符合学位授予条件的，颁发学位证书
- 修完教育教学计划规定内容但未达到毕业要求的，可准予结业，发给结业证书
- 退学学生发给肄业证书或写实性学习证明

## 校园秩序与课外活动

- 学生应当自觉遵守公民道德规范，自觉遵守学校管理制度
- 不得有酗酒、打架斗殴、赌博、吸毒等违法行为
- 不得参与非法传销和进行邪教、封建迷信活动
- 学校提倡并支持学生及学生团体开展有益于身心健康、成长成才的活动

## 奖励与处分

- 学校对在德、智、体、美、劳等方面全面发展的学生给予表彰和奖励
- 处分种类：警告、严重警告、记过、留校察看、开除学籍
- 处分一般设置 6 到 12 个月期限，到期按学校规定程序予以解除

## 学生申诉

- 学校成立学生申诉处理委员会，负责受理学生对处理或处分决定不服提起的申诉
- 学生可在接到处理或处分决定书之日起 **10 日内**向学生申诉处理委员会提出书面申诉
- 学生申诉处理委员会在接到书面申诉之日起 **15 日内**作出复查结论
- 学生对复查决定有异议的，可在接到复查决定书之日起 **15 日内**向山东省教育厅提出书面申诉
