# ⚽ 体育工作实施方案

!!! info "📋 原始文件"
    本页面内容基于《济南大学全面加强和改进新时代体育工作实施方案》整理，详见 [原文](../appendix/教育管理规定/济南大学全面加强和改进新时代体育工作实施方案/济南大学全面加强和改进新时代体育工作实施方案.md)。

## 指导思想

以习近平新时代中国特色社会主义思想为指导，坚持"健康第一"的教育理念，实现以体育智、以体育心、以体育人。

## 工作原则

- **以学生发展为中心**：面向全体学生，健全体育工作体系
- **以改革创新为动力**：深化体育教学改革
- **以特色发展为引领**：打造"一院一品"的体育发展新局面
- **以协同育人为基础**：深化体教融合，建立第一课堂与第二课堂互为补充的工作格局

## 体育课程建设

- 加强体育课程体系建设，探索将体育课程纳入研究生教育公共课程体系
- 充分挖掘体育思政元素，构建课程思政指标体系
- 加强体育课程教材建设，丰富教学资源

## 体育教学改革

- 逐步完善"健康知识+基本运动技能+专项运动技能"的体育教学模式
- 根据学生运动技能水平、体测成绩开展分层教学
- 探索线上、线下紧密结合的体育教学模式

## 体质健康测评

- 积极建设标准化、专业化学生体质健康测试中心
- 定期组织开展学生体质健康测试
- 体质健康测试成绩达标，修满体育学分，方可毕业

## 体育竞赛体系

完善学校、学院、班级、社团**四级体育竞赛体系**：

- **竞技性赛事**：田径运动会、"济大杯"足球赛、篮球赛、排球赛
- **群众性赛事**：校园马拉松、健步走、趣味运动会、啦啦操
- **特色赛事**：高水平运动队和体育精品社团引领的专项竞赛

## 课外体育锻炼

- 保障学生每天课外一个小时体育活动时间
- 开发"济南大学健身APP"进行后台管理监督
- 启动"全员户外课外体育锻炼"专项计划

## 体育文化建设

- 培育"激情运动阳光生活"的体育文化氛围
- 鼓励各学院培育体育活动品牌项目
- 充分利用“第二课堂成绩单”工作制度

## 组织保障

| 保障措施 | 说明 |
| ---------- | ------ |
| 加强组织领导 | 学校学生体育工作委员会全面负责 |
| 加快师资建设 | 配齐配强体育师资力量，聘用优秀退役运动员 |
| 保障工作经费 | 足额保障体育活动经费 |
| 改善运动场地 | 加快体育场馆建设、设施修缮 |
| 探索合作发展 | 吸引社会捐赠，引入社会资金 |
