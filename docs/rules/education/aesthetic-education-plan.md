# 🎨 美育工作实施方案

!!! info "📋 原始文件"
    本页面内容基于《济南大学全面加强和改进新时代美育工作实施方案》整理，详见 [原文](../appendix/教育管理规定/济南大学全面加强和改进新时代美育工作实施方案/济南大学全面加强和改进新时代美育工作实施方案.md)。

## 指导思想

以习近平新时代中国特色社会主义思想为指导，以立德树人为根本，以社会主义核心价值观为引领，以提高学生审美和人文素养为目标，弘扬中华美育精神。

## 工作原则

- **坚持正确方向**：弘扬中华美育精神，传承中华优秀传统文化
- **坚持面向全体**：普及艺术教育，让每个学生都享有接受美育的机会
- **坚持改革创新**：深化美育教学改革，构建具有济大特色的美育体系

## 主要目标

逐步建成多元化、现代化、高质量的美育工作体系，学生审美和人文素养明显提升。

## 美育课程体系

- 加强公共艺术课程建设，丰富美育课程内容
- 将艺术课程纳入研究生教育公共课程体系
- 开发美育优质教学资源，强化课程建设

## 美育教学改革

- 推进美育教学方法改革，创新教学手段
- 加强信息化教学，探索线上线下结合的美育教学模式
- 充分挖掘美育课程的思政元素

## 美育师资建设

- 配齐配强美育师资力量
- 加强美育教师培训，提升专业素养
- 建立美育教师激励机制

## 美育活动

- 丰富校园美育活动，打造美育文化品牌
- 鼓励各学院培育美育活动品牌项目
- 充分利用“第二课堂成绩单”工作制度

## 服务社会

- 推进学校美育场馆向社会开放
- 鼓励学生志愿者走进社区、中小学等宣传美育理念
- 带动提升全民美育水平

## 组织保障

| 保障措施 | 说明 |
| ---------- | ------ |
| 加强组织领导 | 学校学生美育工作委员会全面负责 |
| 保障工作经费 | 足额保障美育活动经费 |
| 改善美育设施 | 加快美育场馆建设、设施修缮 |
