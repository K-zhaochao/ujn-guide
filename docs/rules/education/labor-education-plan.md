# 🛠️ 劳动教育实施方案

!!! info "📋 原始文件"
    本页面内容基于《济南大学全面加强新时代劳动教育实施方案》整理，详见 [原文](../appendix/教育管理规定/济南大学全面加强新时代劳动教育实施方案/济南大学全面加强新时代劳动教育实施方案.md)。

## 指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的教育方针，坚持立德树人根本任务，把劳动教育纳入人才培养全过程。

## 工作原则

- **坚持正确方向**：把握育人导向，引导学生树立正确的劳动观
- **坚持遵循规律**：适应学生年龄特点，注重教育实效
- **坚持因地制宜**：结合学校实际，实施劳动教育
- **坚持协同育人**：家庭、学校、社会共同参与

## 主要目标

构建体现时代要求的劳动教育体系，学生劳动素养明显提升。

## 课程体系

- 将劳动教育纳入人才培养方案
- 开设劳动教育必修课程
- 丰富劳动教育选修课程

## 师资建设

- 配齐配强劳动教育师资力量
- 加强劳动教育教师培训
- 建立劳动教育教师激励机制

## 实践场所

- 建设校内劳动实践基地
- 拓展校外劳动实践场所
- 建立劳动实践基地管理制度

## 劳动实践教育

- 组织学生参加日常生活劳动
- 开展生产劳动和服务性劳动
- 结合实习实训、社会实践开展劳动教育

## 评价体系

- 建立劳动素养评价制度
- 将劳动素养纳入学生综合素质评价
- 定期开展劳动教育质量监测

## 组织保障

| 保障措施 | 说明 |
| ---------- | ------ |
| 加强组织领导 | 学校学生劳动教育工作委员会全面负责 |
| 保障工作经费 | 足额保障劳动教育经费 |
| 改善实践条件 | 加快劳动实践基地建设 |
