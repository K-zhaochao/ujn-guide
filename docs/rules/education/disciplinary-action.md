# ⚖️ 学生违纪处分办法

!!! info "📋 原始文件"
    本页面内容基于《济南大学学生违纪处分办法》（济大校字〔2025〕42号）整理，详见 [原文](../appendix/教育管理规定/济南大学学生违纪处分办法.md)。

## 处分种类

| 种类 | 说明 |
| ------ | ------ |
| **警告** | 最轻处分 |
| **严重警告** | 较轻处分 |
| **记过** | 中等处分 |
| **留校察看** | 较重处分 |
| **开除学籍** | 最重处分 |

## 违纪行为分类

### 扰乱教学秩序

| 行为 | 处分 |
| ------ | ------ |
| 一学期内旷课 10-40 学时 | 警告、严重警告、记过 |
| 一学期内旷课 40 学时及以上 | 留校察看或开除学籍 |
| 考试违纪 | 警告、严重警告或记过 |
| 考试作弊、协同作弊（情节较轻） | 记过 |
| 代替他人考试、使用通讯设备作弊、出售试题答案牟利 | 留校察看或开除学籍 |
| 让他人代替自己考试、组织作弊 | 开除学籍 |
| 抄袭、剽窃他人成果 | 警告直至开除学籍 |
| 学位论文存在抄袭、篡改、伪造等学术不端行为，或代写、买卖论文 | 留校察看或开除学籍 |

### 扰乱生活秩序

| 行为 | 处分 |
| ------ | ------ |
| 打架未致他人受伤 | 警告或严重警告 |
| 打架致他人受伤 | 记过或留校察看 |
| 策划、怂恿、挑唆他人打架 | 记过或留校察看 |
| 故意为他人作伪证 | 警告、严重警告或记过 |
| 违反学生公寓管理规定 | 按《学生公寓管理办法》处分 |

### 扰乱公共场所秩序

| 行为 | 处分 |
| ------ | ------ |
| 故意损坏公共或他人财物 | 警告直至开除学籍（另需照价赔偿） |
| 侮辱、诽谤他人（未造成严重后果） | 记过及以下 |
| 侮辱、诽谤他人（造成严重后果） | 留校察看或开除学籍 |
| 违反网络使用规定 | 警告、严重警告或记过；情节严重者留校察看或开除学籍 |
| 在校内进行宗教活动屡教不改 | 警告、严重警告、记过或留校察看 |

## 处分程序

1. **发现违纪**：职能部门、学院发现违纪行为，收集固定证据
2. **告知学生**：告知拟处分的事实、理由及依据，听取学生陈述和申辩
3. **作出决定**：学生本人在拟处分学生谈话告知记录表中签字确认
4. **送达处分**：处分决定作出后 10 个工作日内送达学生本人
5. **申诉权利**：学生可在收到处分决定书之日起 10 日内向学生申诉处理委员会提出书面申诉

## 处分解除

| 处分种类 | 解除期限 | 解除程序 |
| ---------- | ---------- | ---------- |
| 警告、严重警告 | 6 个月后 | 本人申请、学院同意后解除 |
| 记过 | 9 个月后 | 本人申请、本班同学 2/3 以上表决通过、辅导员鉴定、学院同意、报学工部审核批准 |
| 留校察看 | 12 个月后 | 同上 |

!!! warning "注意"
    - 毕业前一学期受到纪律处分且无悔改表现的，原则上不予解除
    - 受到处分经教育不改的，再次违纪时加重处分
    - 三次受到纪律处分屡教不改的，给予开除学籍处分
    - 留校察看期内再次违纪应受到纪律处分的，给予开除学籍处分

## 处分管理权限

| 处分种类 | 决定权限 |
|----------|----------|
| 记过及以下 | 学院提出意见，学工部/研究生工作部研究决定 |
| 留校察看 | 学院提出意见，学工部审核，报分管校领导批准 |
| 开除学籍 | 学院提出意见，学工部审核，合法性审查后，经校长办公会研究决定，报省教育厅备案 |
