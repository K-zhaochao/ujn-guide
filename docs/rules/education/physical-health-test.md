# 🏃 学生体质健康测试办法

!!! info "📋 原始文件"
    本页面内容基于《济南大学学生体质健康测试工作实施办法》（济大校字〔2025〕22号）整理，详见 [原文](../appendix/教育管理规定/济南大学学生体质健康测试工作实施办法/济南大学学生体质健康测试工作实施办法.md)。

## 基本要求

- 学校全体**在籍本科生**均需参加体质健康测试
- 测试成绩记入学生档案
- 体质健康测试成绩达到规定要求后，方可参加评优评奖

## 测试项目

肺活量、坐位体前屈、50 米跑、立定跳远、引体向上（男）、1 分钟仰卧起坐（女）、1000 米跑（男）、800 米跑（女）

## 成绩计算

### 未被抽查的学生

$$\text{体质健康测试成绩} = \text{学校组织的测试成绩}$$

### 被抽查的学生

$$\text{体质健康测试成绩} = \text{上级抽查成绩} \times 70\% + \max(\text{学校测试成绩}, \text{上级抽查成绩}) \times 30\%$$

## 成绩等级

| 等级 | 分数 |
| ------ | ------ |
| 优秀 | 90.0 分及以上 |
| 良好 | 80.0 - 89.9 分 |
| 及格 | 60.0 - 79.9 分 |
| 不及格 | 59.9 分及以下 |

## 评优评奖要求

| 评优类型 | 成绩要求 |
| ---------- | ---------- |
| 校级评奖评优 | 70 分及以上 |
| 省级及以上评奖评优 | 80 分及以上 |
| 免测学生 | 可参与评奖评优，毕业时注明"免测" |

## 毕业要求

$$\text{毕业体质健康测试成绩} = \text{毕业学年成绩} \times 50\% + \text{其他学年平均成绩} \times 50\%$$

!!! warning "毕业要求"
    毕业时体质健康测试成绩**未达到 50 分**者，按**结业处理**。在修业年限内可申请补测，成绩达到 50 分后可申请毕业。

## 免测申请

学生因患病或残疾（丧失运动劳动能力），可申请暂缓或免予测试：

1. 提供学校认可的医疗机构诊断证明
2. 经学生所在学院、校医院初审
3. 提交至学生体质健康测试办公室核准
4. 填写《免予执行<国家学生体质健康标准>申请表》

## 安全要求

- 测试前应充分做好准备活动
- 必须携带校园卡、身份证等个人证件
- 由本人完成测试，虚开病历、冒名顶替将按违纪处分办法处理
- 长跑测试等环节安排医务人员轮值
