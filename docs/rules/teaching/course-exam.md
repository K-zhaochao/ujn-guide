# 📝 课程考试管理规定

!!! info "📋 原始文件"
    本页面内容基于《济南大学本科生课程考试管理规定》整理，详见 [原文](../appendix/教学管理规定/济南大学本科生课程考试管理规定.md)。

## 考试组织

- 学校统一组织期末考试
- 学院负责具体实施
- 考试安排提前公布

## 成绩评定

- 考试课程采用百分制记分
- 考查课程可采用百分制或五级制记分
- 平时成绩占总成绩的比例由课程负责人确定

## 考试纪律

- 学生应当遵守考场纪律
- 考试违纪、作弊行为按《济南大学学生违纪处分办法》处理

## 成绩查询与复核

- 学生可在规定时间内查询成绩
- 对成绩有异议的，可在规定时间内申请复核
