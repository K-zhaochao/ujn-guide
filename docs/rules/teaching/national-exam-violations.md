# ⚠️ 国家教育考试违规处理办法

!!! info "📋 原始文件"
    本页面内容基于《国家教育考试违规处理办法》整理，详见 [原文](../appendix/教学管理规定/国家教育考试违规处理办法.md)。

## 适用范围

适用于普通高等学校招生考试、成人高等学校招生考试、硕士研究生招生考试等国家教育考试。

## 违规行为认定

### 考生违纪行为

- 携带规定以外的物品进入考场
- 未在规定的座位参加考试
- 考试开始信号发出前答题或考试结束信号发出后继续答题
- 在考试过程中旁窥、交头接耳、互打暗号或手势
- 在考场或教育考试机构禁止的范围内喧哗、吸烟或实施其他影响考场秩序的行为

### 考生作弊行为

- 携带与考试内容相关的材料或存储有与考试内容相关资料的电子设备参加考试
- 抄袭或协助他人抄袭试题答案或与考试内容相关的资料
- 抢夺、窃取他人试卷、答卷或强迫他人为自己抄袭提供方便
- 在考试过程中使用通讯设备
- 由他人冒名代替参加考试
- 故意销毁试卷、答卷或考试材料
- 在答卷上填写与本人身份不符的姓名、考号等信息
- 传、接物品或交换试卷、答卷、草稿纸

## 处理程序

1. 监考人员发现违规行为，应当场予以制止
2. 考试工作人员收集违规证据
3. 考试机构认定违规行为
4. 作出处理决定并送达考生

## 处理结果

| 违规类型 | 处理结果 |
|----------|----------|
| 考生违纪 | 取消该科目的考试成绩 |
| 考生作弊 | 其报名参加考试的各阶段、各科成绩无效 |
| 严重作弊 | 可以给予暂停参加该项考试 1 至 3 年的处理 |
