# 📜 学位授予工作细则

!!! info "📋 原始文件"
    本页面内容基于《济南大学学位授予工作细则》整理，详见 [原文](../appendix/教学管理规定/济南大学学位授予工作细则.md)。

## 学位授予条件

- 完成教育教学计划规定的各项要求，成绩合格
- 通过学位论文（毕业设计）答辩
- 达到学校规定的学位授予标准

## 学位授予程序

1. 学生完成教育教学计划规定的各项要求
2. 学院学位评定分委员会审核
3. 学校学位评定委员会审定
4. 颁发学位证书

## 不授予学位的情形

- 未达到学校规定的学位授予标准
- 学位论文存在抄袭、篡改、伪造等学术不端行为
- 其他不符合学位授予条件的情形
