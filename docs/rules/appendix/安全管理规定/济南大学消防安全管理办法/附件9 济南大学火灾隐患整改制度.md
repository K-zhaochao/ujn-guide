# 附件9

## 济南大学火灾隐患整改制度

一、学校及各部门、各单位应对存在的火灾隐患及时整改。
二、安全管理处和各部门、各单位防火检查或巡查时，检查人员对发现的火灾隐患做好记录，能够当场整改的责令其当场改正。
三、对不能立即整改或存在较大的火灾隐患，应及时提出整改意见或方案，上报学校。
四、学校消防安全责任人或消防安全管理人对整改方案做出明确批示，确定整改措施、期限，落实整改经费，并责令火灾隐患单位或负责整改的部门实施。
五、有火灾隐患的单位或负责整改的部门在整改期限内对火灾隐患整改情况以《消防隐患整改回函》的形式反馈给安全管理处。
六、安全管理处根据回函或整改期限，派人到现场进行复查，对符合整改要求的予以明确肯定，对不符合整改要求的，责令其继续整改。各部门、各单位在火灾隐患未消除之前，应当落实防范措施，保障消防安全。
七、对消防执法单位责令限期改正的火灾隐患，责任单位应当在规定的期限内改正并填写《消防隐患整改回函》，报送安全管理处备案。对逾期未整改，造成火灾事故的，将依法处理。
