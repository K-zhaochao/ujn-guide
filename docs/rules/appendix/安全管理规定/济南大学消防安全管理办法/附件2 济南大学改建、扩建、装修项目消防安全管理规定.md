# 附件2

## 济南大学改建、扩建、装修项目消防安全管理规定

一、凡在学校范围内进行的改建、扩建、装修等施工项目的设计、建筑材料的选用、施工组织方案、消防措施等须报消防监管部门批准后方可施工。

二、施工单位在施工前必须与学校签订消防安全责任书。施工现场的消防安全由施工单位负责，学校安全管理处应督促施工单位做好消防安全工作。

三、施工单位进场施工之前必须先到安全管理处办理进场施工登记。

四、施工单位必须严格遵守《济南大学消防安全管理规定》，并确定一名施工现场防火负责人，全面负责施工现场的消防安全工作。

五、施工过程中，应保证原有消防设施、设备正常使用。如需改动消防设施设备，须报送消防监管部门批准。

六、施工中使用电器设备必须符合消防安全规定，严格防火措施，禁止违章作业电源部分须在学校相关业务部门的协助下开通。

七、施工现场使用明火时，必须事先向安全管理处办理审批手续，领取用火证后方可作业操作。电、气焊的人员必须是持证操作，现场必须满足防火要求。

八、施工中需使用汽油、脱漆剂等易燃物品时必须符合《易燃易爆化学物品消防安全监督管理办法》的规定。易燃品要有专用库房，由专人保管，不得将易燃易爆物品存放在施工现场内。

九、施工中不准大面积使用脱漆剂等易燃液体，尽可能不在现场进行喷漆作业。如必须在现场喷漆时，要有良好的通风和防止明火的措施。

十、施工中使用易燃易爆化学物品应限额领料，随用随领，禁止在作业场所分装、调料，禁止在工程现场使用液化石油气钢瓶、乙炔发生器等。

十一、施工的堆料和垃圾，不得圈占消防设备，不得堵塞走廊、楼梯和疏散通道。

十二、本规定自发布之日起施行，由安全管理处负责解释。
