# 附件6

## 济南大学消防安全承诺书

为进一步加强消防安全管理，做好本部门（单位）火灾防控工作，更好遵守消防法律、法规和相关制度规定，确保消防安全，严防火灾事故发生，特郑重做出如下承诺：

一、严格落实消防安全责任制，明确各岗位消防安全职责，确定各岗位消防安全责任人，层层签订责任状，做到分工明确、责任到人，确保各项防火安全措施落实到位。

二、开展常态化消防安全教育培训，制定本部门（单位）灭火和应急疏散预案并组织演练，提升消防安全“四个能力”建设水平，确保师生员工全面掌握消防安全“四懂四会”基本常识。

三、按照《济南大学消防安全管理办法（试行）》中明确的职责要求开展消防安全管理工作，按照规定的频次、内容开展消防安全检查、巡查，及时制止、纠正不安全用火行为，及时发现并消除火灾隐患。

四、加强所属消防设施、器材管理使用，确保其完好有效，不损坏、挪用或者擅自拆除、停用消防设施、器材，不埋压、圈占、遮挡消火栓、灭火器，发现问题隐患及时上报学校相关部门。

五、确保所属建（构）筑物疏散通道、安全出口、消防车通道畅通，不占用防火间距，不堵塞消防、逃生通道。

六、加强易燃易爆及化学危险品使用管理，不违章使用明火作业，严格落实用火、用电、用气、用油管理制度。

七、新建、改建、扩建、装修、装饰等活动，应严格执行消防法规和国家工程建设消防技术标准，并依法办理建设工程消防设计审核、消防验收或者备案手续。

八、对检查中发现的火灾隐患，明确专人负责，积极投入资金，组织人力物力，严格按要求落实整改，并采取有效措施，确保不发生火灾事故。

九、在重要节假日、敏感时间节点以及重大活动期间采取有效防范措施，确保消防安全。

本承诺书一式两份，学校和承诺人各执一份，学校一份由党委保卫部安全管理处统一保存。
