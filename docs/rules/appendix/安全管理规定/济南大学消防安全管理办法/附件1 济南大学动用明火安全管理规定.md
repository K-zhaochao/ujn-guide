# 附件1

## 济南大学动用明火安全管理规定

为进一步加强校园动用明火管理，严格规范我校消防安全工作，有效预防校园火灾的发生，根据《中华人民共和国消防法》、《高等学校消防安全管理规定》和《济南大学消防安全管理规定》等相关法律、法规，结合学校实际，特制定本规定。

第一条 本规定所称动用明火，系指焚烧、实验、电气焊割等用火行为。

第二条 校内动用明火坚持“谁动火，谁负责；谁动火，谁管理”的安全管理原则，全体师生员工应自觉遵守本规定，安全管理处负责监督和管理校内所有动用明火行为，各部门、各单位具体执行和落实。

第三条 禁止携带火种、火源等易燃易爆物进入校内消防重点部位。

第四条 禁止在具有火灾、爆炸危险的场所吸烟、使用明火。

第五条 禁止在校内燃放烟花爆竹和孔明灯，确因重大节庆活动需燃放烟花爆竹的，需经政府部门同意并报学校批准，在指定时间地点燃放。

第六条 禁止在校园建筑物内及道路、山上焚烧废纸、垃圾和枯枝落叶等废弃物。

第七条 因实验、施工等特殊原因，确需动用明火的，使用单位必须事先向安全管理处提出用火申请，经审批同意，取得《济南大学校内动火动气备案审批表》后方可动火。
需要向政府消防机构申报动火作业的，必须到消防机构办理审批手续，经审批同意后方可动火。

第八条 各部门、各单位主管领导根据“谁动火，谁负责；谁动火，谁管理”的安全管理原则，对动火作业承担管理责任，与施工单位签订施工现场消防安全责任书，电焊、气焊（割）作业必须严格遵守消防安全操作规程，作业地点应当符合安全要求，并采取可靠的防范措施，报合格后方可进行作业。作业前应检查电、气焊工具，保证安全可靠。电、气焊操作人员必须持证上岗。

第九条 《济南大学校内动火动气备案审批表》不得连续使用，每动用一次必须申报一次。动火动气备案审批表上要如实填写以下事项：
（一）申请单位、动火事由、动火时间、动火地点、动火人、现场监管人及联系方式；电、气焊操作人员有效证件名称及编号。
（二）安全防护措施、动火用具及燃料；
（三）申请单位意见、主管人、审批意见、审批人和审批时间。

第十条 外单位在学校新建区域和现有建筑区域因施工、改造、检修动用明火，由学校主管单位填写《济南大学校内动火动气备案审批表》，经安全管理处审批后，方可施工。

第十一条 动火现场监管人在动火作业过程中，应随身携带动火动气备案审批表以备安全管理处查验，并不得超出动火证规定范围动用明火。

第十二条 任何单位和个人在未取得消防部门或学校安全管理处签发的动火动气备案审批表前不得在校内动用明火，违者主管单位和责任人将做出书面检查并通报批评。引发财产损失和人员伤亡的，主管单位和责任人将承担法律责任。

第十三条 对违反本规定擅自动用明火，造成火灾事故，导致财产损失和人员伤亡的，主管单位和责任人将交由政府消防部门按规定处罚；情节严重构成犯罪的，移交司法部门依法追究刑事责任。

第十四条 本规定自发布之日起施行，由安全管理处负责解释。

## 备注

1. 各单位需要在校内动火（如使用电焊、气焊、喷灯、熬炼和焚烧等作业）动气都需办理备案审批，不准擅自动火动气作业。
2. 动火动气人应逐项认真填写，动火动气单位和施工单位安全负责人签字并加盖公章，于动火动气前三日送安全管理处审查。
3. 施工作业单位在动火动气前应对施工场所易燃易爆物品认真进行清理和检查，施工后不留火种。
4. 动火动气现场须保持道路畅通，并根据火的种类不同，采取不同的防火措施，配备相应的消防器材，并派有一定经验、责任心强的人员担任监护人。
5. 电、气焊操作人员要持有效证件上岗，非焊工严禁操作。
6. 五级风以上（含五级）不许在室外明火作业。
7. 动火动气备案审批表一式两份，一份由动火动气单位自存备查，一份交安全管理处存档。
