# 附件8

## 济南大学微型消防站日常管理制度

一、微型消防站实行24小时巡查制度，指定专人负责。
二、接到火灾报警时，消控室值班员必须立即核实火警，启动灭火处置程序。微型消防站队员应按照“60秒到场”要求赶赴现场，利用岗位上或起火部位就近的灭火器材展开灭火行动，并视火场情况拨打“119”报警。
三、属地消防救援机构人员到达现场后，微型消防站人员应立即汇报火场情况，接受消防救援机构人员统一指挥。
四、消防站必须严格执行器材（装备）管理的有关要求，遵守维护保养、保管、检查制度和使用规定，经常检查，防止器材（装备）损坏、丢失、锈蚀和失效，保证器材（装备）始终处于良好状态。所有执勤战备器材，不得用于非灭火和救援行动。
五、消防队员每两周必须进行一次消防技能训练，每月进行一次重点部位演练，每半年参加一次单位组织的综合演练，努力提高身体素质和灭火技能。
六、微型消防站应纳入属地消防救援机构联勤联动体系，接受属地消防救援机构“一呼百应”指挥调度，积极参与周边区域灭火救援处置工作。
