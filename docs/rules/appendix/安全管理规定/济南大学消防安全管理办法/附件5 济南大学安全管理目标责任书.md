# 附件5

## 济南大学安全管理目标责任书

为全面落实安全工作责任，不断深化“平安校园”建设，有效防止安全事故和各种案件发生，维护正常的教学、科研、工作和生活秩序，确保学校和师生员工生命财产的安全，根据有关法律、法规、规章和上级文件要求，按照“谁主管、谁负责”和“党政同责、一岗双责、齐抓共管、尽职免责、失职追责”的原则，签订本责任书。

# 一、责任目标

（一）安全理念到位，思想意识重视。按照党的二十大报告提出的“坚持安全第一、预防为主，建立大安全大应急框架，完善公共安全体系，推动公共安全治理模式向事前预防转型”要求，树牢安全发展理念，从思想意识上高度重视，以人为本，把师生生命安全摆在首位，进一步增强忧患意识、责任意识，从源头上防范化解重大安全风险。

（二）组织领导到位，责任体系完善。制有年度安全工作计划，每学期至少进行一次专题研究，研究部署安全稳定工作，并形成会议纪要；成立主要领导任组长的安全工作领导小组，确定安全管理员，严格实行安全责任制和责任追究制。

（三）制度建设到位，运行机制健全。按照规定要求建立相关安全工作制度，相关岗位管理和工作人员对具体相关安全制度知晓率达到100%。建有完善的信息工作机制、安全隐患排查整治机制、矛盾纠纷排查调处机制和内外沟通协调机制。

（四）政保工作到位，单位政治稳定。意识形态、保密、抵御和防范各种敌对势力渗透破坏、防范和处理宗教邪教渗透和国家安全教育与人民防线建设工作落实的好，有切实可行工作方案，健全课堂、讲座、论坛、刊物和网站等阵地管理制度，定期分析研判意识形态领域形势，不发生有害政治信息传播、扩散事件，积极创建“无邪教”“无传销”“无诈骗”“零发案”单位。

（五）日常管理到位，常规安全落实。消防和实验室安全的责任目标，以学校消防安全承诺书、实验室安全责任书设定的目标为准；治安、交通安全、饮食安全、公共卫生安全、大型活动安全、实习实践活动安全、防诈骗传销、校舍安全、自然灾害预防等安全管理规范有效，无安全责任事故和治安案件、刑事案件发生。

（六）风险防控到位，应急管理有效。风险防控措施切实落实，无因未对重大决策、重大事项进行风险评估造成较大以上损失事件。应急准备工作全面到位；每学期至少组织一次防震、防火、防汛、防踩踏等突发事件应急演练，参与率达到本单位总人数的95%以上；应急处置措施得力，能够最大限度减少突发事件的社会影响和现实危害。

（七）安全教育到位，安全文化优良。制有年度安全教育计划，加强专兼职安全师资队伍建设，落实安全教育“三进”（进课堂、进教材、进学分）工作；开展国家安全、法律法规、心理健康和安全知识教育与技能培训，建立心理危机预警与干预机制，提高师生防范意识和自救能力；安全宣传形式多样，引导师生把抓安全、讲安全、保安全作为自己的责任，所属人员有安全文化共识、安全工作责任感强、自觉性高。

（八）队伍建设到位，保障措施有力。按照要求建强单位内部安全管理骨干队伍；群防群治队伍建设好，全员参与安全管理。设有年度安全工作经费预算，单位内部安防设施达标建设，信息化水平不断提升。

# 二、责任内容

（一）加强安全工作组织领导。将安全工作列入单位（部门）党委会和党政联席会议事日程，坚持常抓常议，制定切实可行的计划措施；健全组织机构，明确安全工作领导小组成员和职责要求；落实一岗双责，明确单位主要领导是单位安全责任人、分管安全领导是单位安全管理人和分管业务领导的安全职责，建立健全责任追究制度；落实单位内部逐级安全责任制和岗位安全责任制，并签订安全管理目标责任书；将安全工作纳入评优先、绩效考核工作体系，做到奖惩分明。在显著位置公示安全工作领导小组成员及相关责任人。

（二）健全安全制度和运行机制。认真学习《山东省学校安全条例》（以下简称条例）、《山东省学校安全条例实施细则（以下简称实施细则）、《山东省高等学校安全管理暂行办法》（以下简称暂行办法）、山东省实施《地方党政领导干部安全生产责任制规定》细则（以下简称细则）和学校安全管理有关规定，贯彻落实相关安全工作制度。建立健全单位内部安全管理运行机制，建好安全员队伍，保证信息收集报送顺畅、分析研判充分、防范措施到位；建立安全隐患排查整治机制，定期排查安全隐患并形成台账，落实安全隐患整改措施；建立矛盾纠纷排查调处机制，及时调处、化解各种矛盾，严防影响稳定的群体性事件发生；建立与学校相关部门的沟通协调机制，开展形式多样的联动活动。

（三）切实做好政保维稳工作。做好意识形态工作，健全阵地管理制度，规范阵地管理；健全网站管理制度措施，严防有害政治信息传播、扩散事件；适时开展重点人群摸底排查，建立工作台账，落实管理责任人和教育转化与稳控措施。做好保密工作，认真贯彻落实保密法规制度，安排专人负责单位保密工作；积极参加保密教育培训，签订《保密承诺书》，加强对保密文件、档案、科研项目、涉密载体和涉密人员的管理；加强保密要害部位安全防范设施建设，杜绝涉密信息违规上网等；定期开展保密检查，保证各项保密工作措施落实到位。做好抵御和防范各种敌对势力渗透破坏工作，制定切实可行的工作方案；严格落实外事活动管理制度，认真履行对外交流活动审批报告手续；加强对外籍教师和留学生的管理；积极防范“三股势力”渗透，做到措施有力。做好防范和处理宗教邪教渗透工作，制定工作方案，防范和处理措施明确；加强日常巡查管控，严防非法宗教活动；落实教育管理，防止出现失控漏管人员。做好国家安全教育与人民防线建设工作，落实总体国家安全观，积极宣传国家安全法；加强所属人员国家安全教育，对出国（境）人员进行回访，提高所属人员国家安全意识。

（四）规范开展常规安全管理。规范实施消防管理，消防法律、法规和学校消防管理规定，制定并落实本单位的消防安全管理制度和措施，按照“谁管理、谁负责”及“谁使用、谁负责”的原则，运用逐级消防安全责任制和岗位消防安全责任制具体明确各级、各岗位消防安全责任人，严密组织消防安全考核与奖惩，制定完善灭火和应急疏散预案，开展经常性消防安全教育培训及演练，定期进行防火检查及消防设施检查，确保疏散通道、安全出口畅通，及时消除火灾隐患。新建、扩建、改建及装饰装修工程报学校消防机构备案，按照规定的程序与措施落实火灾处置预案，依据《高等学校消防安全管理规定》要求做好消防安全重点部位和大型活动的消防安全工作。学生宿舍管理部门还应当建立由学生参加的志愿消防组织、定期进行消防演练，加强学生宿舍用电安全教育与检查，加强防火巡查，发现火灾立即组织扑救和疏散学生。规范实施实验室安全管理，实验室安全管理制度健全，已经制定实验室安全应急制度、实验室安全管理实施细则、危险化学品管理实施细则、实验室安全自查制度、实验室人员进入登记制度、人员培训和考核制度、安全保卫制度等；实验室环境和设施符合安全需要，不存在不具备生物实验条件的普通实验室进行生物实验的情况，不存在重大安全隐患；实验室所产生的废液、废渣或过期药品等实验室废物已委托具有处置资质的专业公司处置，实验室废物产生和处置登记台账清楚；实验室安全管理各相关人员熟知应急预案，保证突发事件发生时能够及时采取有效应对措施。规范实施治安管理，落实人防、物防、技防措施；按照规定对重点要害部位开展巡查，确保重点要害部位安全；严格执行校门和办公、教学、公寓等楼宇出入管理制度和节假日单位内部值班巡逻制度；所属人员不存放、不携带、不使用管制刀具和各种违禁品；采取有力措施预防违法犯罪。规范实施交通安全管理，加强所属人员校内行车和停放车辆管理，做到严格按照规定行驶和停放车辆；积极配合学校开展车辆停放秩序整治，保证单位周边或分管区域车辆停放规范有序；教育引导所属人员自觉遵守校内交通规则，防止交通事故发生。规范实施饮食安全管理，严格执行饮食安全各项规定要求，制定并落实相关工作措施；对所属人员开展经常性教育管理，防止食物中毒事故发生。规范实施公共卫生安全管理，严格执行卫生管理、督查、责任追究制度；按照相关规定协调物业人员对重点部位定期消毒；开展全员公共安全知识普及教育；落实传染病防控措施到位。规范实施大型活动安全管理，严格执行大型活动报告审批制度，制定应急预案；活动安全责任人明确，活动场所、部位安全管理措施到位。规范实施实习实践安全管理，设立实习实践安全工作小组；严格落实实习实践安全制度、操作规程和安全措施；将安全责任落实到每个参加实习实践活动人员。规范实施防诈骗传销管理，制定防范诈骗、传销工作方案；落实经常性防范诈骗宣传教育；发现问题及时妥善有效处理。规范实施校舍安全管理，严格执行校舍及内部设施定期检查报告、维护维修、改造验收制度；协调有关部门对单位使用的老化校舍、陈旧设施及时改造更新，单位无私自搭建和危房危墙。规范实施预防自然灾害管理，制定防范自然灾害应急预案；定期开展应急处置演练。

（五）落实风险防控和应急管理。制定风险防控评估制度；排查辨识单位内部安全风险源；落实风险防控措施；对单位重大决策、重大事项进行风险评估。制定单位各类各种应急预案；加强对应急人员的业务培训，不断提高处置突发事件的能力和水平；按照规定组织应急演练；根据新情况新要求及时修订各专项应急预案；应急响应迅速，措施得力，处置到位，善后工作到位。

（六）精细做好学生安全管理。经常性开展安全纪律巡查，发现安全漏洞和隐患苗头，及时做好补救、处置；将思想政治和德育工作贯穿于教育教学各个环节，结合学生身心发展和思想状况，丰富学生管理工作内容和形式，引导学生尊法学法守法用法，进一步提高辨别是非和安全防范能力；加强教学环节和课外活动的安全教育管理；开展防溺水、心理健康教育，加强学生欺凌和暴力防范，每学期学院领导班子应当至少召开1次办公会专题研究；组织学生实习实训时，应当会同实习单位加强安全教育，制定学生实习安全管理办法和突发事件应急预案，根据国家有关规定，为实习学生投保实习责任保险，不得安排学生到影响身心健康的场所和岗位。

（七）抓好安全教育文化工作。制定安全教育计划，按照《条例》、《实施细则》、《暂行办法》和学校要求落实相关安全教育培训内容，确保人员、时间、效果到位；加强兼职安全师资队伍建设，保证安全教育授课质量；建立安全教育考核机制，定期组织所属人员安全教育知识测试。加强心理健康教育，健全心理健康教育工作网络，建立一人一档的心理档案，组织开展心理咨询服务，建立心理危机预防与干预机制，针对在心理筛查中排查出有心理问题的学生，制定针对性的帮扶方案，及时转介疑似患有严重心理或精神疾病的学生到专业机构接受诊断和治疗，防止各种问题发生。注重安全文化建设，开展形式多样的安全宣传教育活动，在校园宣传栏、网站及“两微一端”设置安全教育栏，引导帮助所属人员树立科学鲜明的安全文化理念、形成安全文化共识。

（八）加强队伍建设和经费保障。加强队伍参与、齐抓共管的安全工作格局。加强安防设施与信息化建设，根据实际需要配备必要的安防设施，推动安防工作智能化、信息化。

# 三、责任追究

（一）本责任书落实情况纳入学校年度工作考核指标体系，有下列负面清单之一的情形，两年内取消该单位各类评选先进资格：一是主要领导有严重违纪、违法事件；二是意识形态领域出现严重错误倾向；三是有影响社会稳定的重大事故、重大不诚信事件；四是有重大安全责任事故、重大消防责任事故、重大食物中毒事件；五是有造成重大社会影响的师生员工违法犯罪案件。

（二）凡是因违反责任书规定而导致发生较大事故、案件和群体性事件的，学校将根据情节轻重和损失大小，对有关责任人依法给予处分；对构成犯罪的，依法追究法律责任。

本责任书一式贰份，学校、各部门、各单位各持一份；自双方盖章签字之日起执行，有效期为四年，期间负责人如有变动，继任者继续履行责任。
