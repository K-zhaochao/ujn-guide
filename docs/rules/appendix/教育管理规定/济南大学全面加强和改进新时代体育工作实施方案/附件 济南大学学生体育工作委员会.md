# 附件 济南大学学生体育工作委员会

## 一、组织架构

1. 主任：学校党委书记、校长
2. 副主任：分管学生工作、本科教学工作、研究生教学工作的校领导
3. 成员（按部门单位习惯顺序排序）：
党委办公室 校长办公室、党委宣传部、党委学生工作部(处)、党委保卫部 安全管理处、党委教师工作部 教师发展中心、教务处、党委研究生工作部 研究生院、实验室与资产管理处、计划财务处、后勤管理处、合作发展处、信息管理处、团委、体育学院等部门单位负责人

## 二、办公室设置

学生体育工作委员会办公室设在党委学生工作部(处)，办公室主任由党委学生工作部(处)部(处)长兼任。

## 三、人员调整规则

学生体育工作委员会人员随工作变动自然调整。
