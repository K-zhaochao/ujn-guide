# 附件1

## 济南大学学生美育工作委员会

### 主任

学校党委书记、校长

### 副主任

分管学生工作、本科教学工作、研究生教学工作的校领导

### 成员（按部门单位习惯顺序排序）

党委宣传部、党委统战部、党委学生工作部（处）、党委教师工作部教师发展中心、人力资源处、教务处、党委研究生工作部 研究生院、国际合作与交流处、实验室与资产管理处、计划财务处、合作发展处、团委、图书馆、文学院、美术与设计学院、音乐学院等部门单位负责人

学生美育工作委员会办公室设在教务处，办公室主任由教务处处长兼任。

学生美育工作委员会人员随工作变动自然调整。
