# 附件2

## 济南大学“三类十项”劳动教育清单

### 一、家庭劳动教育

1. 每学年利用假期参加家居清洁、收纳整理、烹饪制作、孝亲敬老爱幼等力所能及的家务劳动。

### 二、学校劳动教育

1. 每周二下午为宿舍卫生劳动日，以宿舍为单位开展宿舍卫生整理，日常实行学生轮流值日制度，塑造学生日常生活劳动第一场景。
2. 每学年设立集体劳动周，以班级为单位，利用空课时间开展校园卫生责任区清洁、图书馆图书整理、实验室卫生清洁和实验设施设备简单维护等公益劳动；及时应对极端天气，开展义务扫雪等活动。
3. 参加生活帮护、心理辅导、学业帮扶或赛会服务等志愿服务或手工制作、维修服务、熨烫衣服等社团服务劳动。
4. 参加“美食制作”“学生馆员”“校园安全员”“消防安全员”“楼宇值班员”“学生服务校园监督员”“秩序维护员”“网络维护员”等校园服务实践岗位。
5. 修读1门劳育课程，鼓励各学院开设劳动技能类、美食文化类、工匠制作类、劳动美育类等劳育课程；每年组织开展一次劳动技能竞赛、成果展示。

### 三、社会劳动教育

1. 每学年利用假期深入田间地头、车间、工地、商场、医院、企业、社区、学校等劳动场所，开展爱农助农、实践调研、理论宣讲、义务支教、志愿服务、应急救援、回访母校、“三下乡”等社会实践劳动。
2. 每学年结合专业特点，开展实习实训、专业服务和创新创业等专业劳动锻炼。
3. 通过精准实施就业力提升计划，开展校企对接联络，探索建立学生劳动实践基地，鼓励学生到党政机关、企事业单位、社区基层等参加职业体验，参加“三支一扶”、大学生志愿服务西部计划。
4. 考取劳动技能应用和提升的资格（执业）证书，参加志愿者注册和星级认证。
