# 附件1

## 济南大学学生劳动教育工作委员会

### 主任

学校党委书记、校长

### 副主任

分管学生工作、本科教学工作、研究生教学工作、后勤工作的校领导

### 成员

党委办公室、校长办公室、党委组织部、党委宣传部、党委学生工作部(处)、党委保卫部 安全管理处、人力资源处、教务处、党委研究生工作部 研究生院、实验室与资产管理处、计划财务处、后勤管理处、基建处、合作发展处、团委、图书馆等部门单位负责人，各教学学院党委书记、院长

学生劳动教育工作委员会办公室设在党委学生工作部(处)，办公室主任由党委学生工作部(处)部长兼任。

学生劳动教育工作委员会人员随工作变动自然调整。
