# 附件 济南大学第二课堂活动积分设置参考标准

根据团中央对“第二课堂成绩单”活动体系的要求，结合济南大学工作实际，制定济南大学第二课堂活动积分设置参考标准。

# 一、通用积分标准

学生参加或组织各级各类第二课堂活动即可按照通用标准要求获得相应积分。

1. 活动参加者：参加国家级、省级、校级、院级、班级（社团）组织的各项活动，国家级活动每参与一次积6分；省级活动每参与一次积5分；校级活动每参与一次且单次活动参与时长不低于40分钟的积3分，院级活动每参与一次且单次活动参与时长不低于40分钟的积1.5分，班级（社团）活动每参与一次且单次活动参与时长不低于40分钟的积1分。
2. 活动组织者：组织国家级、省级、校级、院级、班级（社团）的各项活动且组织者名单提前通过到梦空间系统备案的，国家级活动每组织一次积8分；省级活动每组织一次积6分；校级活动每组织一次积4分；院级活动每组织一次积2分；班级（社团）活动每组织一次积1分。活动组织者同时参加活动的，不再对参加第二课堂活动进行积分。

# 二、细分项目积分标准

学生参加或组织各级各类第二课堂活动时取得下列成绩，除获得通用积分标准分外，按照以下标准获得积分。

## （一）思想成长

1. 参加党校、团校、青马工程培训且考核合格的，国家级培训每次积7分，省级培训每次积5分，校级培训每次积3分，院级培训每次积2分。

## （二）实践实习

2. 参加暑期“三下乡”社会实践活动及寒假“返家乡”社会实践活动，获评国家级团队的，团队成员积9分；获评省级团队的，团队成员积7分；获评校级团队的，团队成员积5分，院级团队成员积3分；分散实践团队成员积2分。
2. 参加省级及以上社会调查并获奖的，一等奖积9分，二等奖积7分，三等奖积5分。
3. 参加团中央“百万大学生进社区”“社区青春行动”，团省委“青鸟计划”等实践活动专项，并提供证明，每次积2分。
4. 参加出国访学并提供有效证明（交换生满6个月），一次积6分，参加海外夏令营类实践项目并提供有效证明（满2周），一次积4分。参加其他实践实习活动提供有效证明的，每参加一次积1分。

## （三）志愿公益

6. 参加中国青年志愿服务项目大赛，获得国家级金、银、铜奖分别积30分、25分、20分；获得省级金、银、铜奖分别积20分、15分、10分；获得市级或校级金、银、铜奖分别积5分、4分、3分。
2. 参加省级及以上志愿服务品牌活动并提供证明，一次积5分；市级或校级志愿服务品牌活动并提供证明，一次积3分；院级志愿服务品牌活动并提供证明，一次积2分。

## （四）创新创业

8. 作为第一发明人，以济南大学为专利权人的，每获得一项发明专利积25分，每获得一项实用新型专利积10分，每获得一项外观设计专利积5分；作为主持人，以济南大学为著作权人的，每获得一项计算机软件著作权积5分。
2. 参加一类科创赛事且获奖的，国家级一（金）等奖及以上、二（银）、三（铜）等奖分别积30分、25分、20分；省级一（金）等奖及以上、二（银）、三（铜）等奖分别积20分、15分、10分；市级及以上、二（银）、三（铜）等奖分别积10分、7分、5分。同一项目参加同一赛事不同阶段的不重复计分，以最高分计入。以上均为个人项目积分标准，团体项目按集体项目积分认定标准执行。
3. 参加二类科创赛事且获奖的，国家级一（金）等奖及以上、二（银）、三（铜）等奖分别积20分、15分、10分；省级一（金）等奖及以上、二（银）、三（铜）等奖分别积10分、7分、5分；校级一（金）等奖及以上、二（银）、三（铜）等奖分别积5分、3分、2分。同一项目参加同一赛事不同阶段的不重复计分，以最高分计入。以上均为个人项目积分标准，团体项目按集体项目积分认定标准执行。
4. 学生获得国家级大学生创新创业训练计划立项的，每项积20分；获得省级大学生创新创业训练计划立项的，每项积10分；获得校级大学生创新创业训练计划立项的，每项积5分；学生参与其他创新创业项目研究及实践，酌情予以积分。以上均为个人项目积分标准，团体项目按集体项目积分认定标准执行。
5. 学生以济南大学为第一署名单位发表高水平及以上论文的，每篇积25分；学生以济南大学为第一署名单位在核心期刊发表论文的，每篇积15分；学生以济南大学为第一署名单位在一般期刊发表专业或兴趣爱好类文章的，每篇积5分。学生以独著身份出版专著的，每本积25分，合著的按集体项目积分认定标准执行。

## （五）文化活动

13. 学生参与学术、文艺、体育、人文素养等各级各类校园文化活动且获奖的，国家级一（金）等奖及以上、二（银）、三（铜）等奖分别积20分、15分、10分；省级一（金）等奖及以上、二（银）、三（铜）等奖分别积9分、7分、5分；市级或校级一（金）等奖及以上、二（银）、三（铜）等奖分别积5分、4分、3分；院级或社团一（金）等奖及以上、二（银）、三（铜）等奖分别积3分、2分、1分。

## （六）社会工作

14. 学生在校级、院级、班级（社团）等学生组织工作的，校级主席团成员、部长团成员、工作人员分别积4分、3分、2分；院级主席团成员、部长团成员、工作人员分别积3分、2分、1分；班级、团支部主要学生干部及社团主要负责人积2分，其他学生干部积1分。每学年积分一次，在多个学生组织工作的，以该学年担任最高职务积分，不重复积分。

## （七）技能特长

15. 学生参加国家认可的各种专业技术培训并获得相应证书，每获得一项积5分；学生参加省级及以上专项技能培训，并能提供证明的，每一项积3分；学生参加市级、校级专项技能培训，并能提供证明的，每项积2分。

## （八）其他

16. 学生在各级各类媒体发表与学校、学院工作相关文章的，国家级媒体每发表一篇积10分，省级媒体每发表一篇积5分，校级媒体每发表一篇积2分。制作并被采纳的新媒体文化产品参照此条积分。
2. 各学生组织（含班级）常规例会等事务性工作（主题团班会除外）、培训，学生艺术团、社团常规训练、内部活动等不认定积分。

# 三、补充说明

## （一）项目定级标准

团中央、教育部等国务院各部（委）以及国家级各社会团体举办的活动按国家级活动认证；山东省委省政府及其下属的各厅（委）如团省委、教育厅等各有关部门以及省级各社会团体举办的活动按省级活动认证；市级政府及主要党政部门和团市委举办的活动、学校各部门如团委等发起的面向全校范围内的活动按校级活动认证；校级学生组织、各学院发起的活动按院级活动认证；校级学生组织相关部门、院级学生组织、学院指导的社团、班级、团支部发起的活动按班/部落级活动认证。学生参加活动的级别认定以实际举办单位（表彰单位）所属级别为准。

## （二）集体项目积分认定标准

集体项目中个人积分获得按贡献程度计量：

1. 贡献程度一致的，如合唱比赛、篮球赛等集体活动，团队成员获得同样积分；
2. 贡献程度有差异的，如科创类、志愿服务类赛事和活动，按照成员在团队中的排名和贡献情况积积分计算如下：成员分值 = 分值标准 × $(N - M + 1)/N$（$N$:完成总人数；$M$:所在位次）。

## （三）积分扣除标准

在“第二课堂成绩单”制度实施过程中，对弄虚作假获得积分的学生，经查实认定，取消其相应积分，并视情节轻重酌情扣1至5个积分；对违规操作的学生组织，经查实认定，视情节轻重对相关责任人酌情扣1至5个积分。
