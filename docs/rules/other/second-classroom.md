# ⭐ 第二课堂成绩单实施办法

!!! info "📋 原始文件"
    本页面内容基于《济南大学“第二课堂成绩单”实施办法》整理，详见 [原文](../appendix/济南大学“第二课堂成绩单”实施办法/济南大学“第二课堂成绩单”实施办法.md)。

## 总则

- 第二课堂成绩单是记录学生参与第二课堂活动的重要载体
- 旨在引导学生全面发展，提升综合素质

## 活动类型

| 类别 | 说明 |
| ------ | ------ |
| 思想政治引领 | 党团活动、主题教育等 |
| 创新创业创造 | 科技竞赛、创新创业项目等 |
| 实践实习实践 | 社会实践、志愿服务等 |
| 文体素质拓展 | 文艺活动、体育竞赛等 |
| 技能特长培养 | 技能培训、证书考取等 |
| 工作履历 | 学生干部经历等 |

## 积分设置

| 活动类型 | 积分标准 |
| ---------- | ---------- |
| 思想政治引领 | 根据活动级别和参与程度确定 |
| 创新创业创造 | 根据竞赛级别和获奖等级确定 |
| 实践实习实践 | 根据实践时长和成果确定 |
| 文体素质拓展 | 根据活动级别和参与程度确定 |
| 技能特长培养 | 根据证书级别确定 |
| 工作履历 | 根据职务级别和任期确定 |

## 成绩单使用

- 第二课堂成绩单作为学生综合素质评价的重要依据
- 作为评优评奖、推免保研的重要参考
- 作为用人单位了解学生综合素质的重要参考
