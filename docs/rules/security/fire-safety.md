# 🔥 消防安全管理办法

!!! info "📋 原始文件"
    本页面内容基于《济南大学消防安全管理办法》整理，详见 [原文](../appendix/安全管理规定/济南大学消防安全管理办法/济南大学消防安全管理办法.md)。

## 消防安全责任

- 学校实行逐级消防安全责任制
- 各单位主要负责人为本单位消防安全第一责任人
- 全体师生员工都有维护消防安全的义务

## 设施管理

- 消防设施、器材应当定期检查、维护
- 不得损坏或擅自挪用消防设施、器材
- 不得堵塞消防通道

## 防火管理

- 不得在校园内使用明火
- 不得在校园内存放易燃易爆物品
- 不得私拉电线、违规使用电器

## 应急预案

- 学校制定灭火和应急疏散预案
- 定期组织消防演练
- 发生火灾时，应当立即报警并组织疏散
