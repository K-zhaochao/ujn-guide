# 🏫 校园秩序管理规定

!!! info "📋 原始文件"
    本页面内容基于《济南大学校园秩序管理规定》整理，详见 [原文](../appendix/安全管理规定/济南大学校园秩序管理规定.md)。

## 校园通行

- 本校师生凭有效证件进出校园
- 外来人员应当登记后方可进入校园
- 车辆应当按照规定路线行驶和停放

## 活动管理

- 在校园内举办大型活动，应当经学校批准
- 不得在校园内进行非法集会、游行、示威
- 不得在校园内进行宗教活动

## 设施保护

- 爱护校园公共设施
- 不得损坏校园绿化
- 不得在校园内乱贴乱画

## 环境维护

- 保持校园环境整洁
- 不得在校园内乱扔垃圾
- 不得在校园内吸烟
