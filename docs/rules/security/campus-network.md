# 📶 校园网使用管理规定

!!! info "📋 原始文件"
    本页面内容基于《济南大学校园网使用管理规定》整理，详见 [原文](../appendix/安全管理规定/济南大学校园网使用管理规定.md)。

## 网络接入

- 本校师生可申请使用校园网
- 校园网账号实行实名制管理
- 不得盗用他人账号

## 使用规范

- 遵守国家法律法规和学校规章制度
- 不得利用校园网从事危害国家安全的活动
- 不得利用校园网传播违法信息
- 不得利用校园网进行商业活动

## 安全管理

- 不得攻击、侵入他人计算机和网络系统
- 不得制作、传播计算机病毒
- 不得盗用他人IP地址

## 违规处理

违反校园网使用管理规定的，按照《济南大学学生违纪处分办法》给予处分。
