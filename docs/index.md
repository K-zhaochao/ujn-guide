## 🌟 关于本站

欢迎来到“济南大学校园通”！

这是一份由济大学子自发整理、维护的开源校园生存指南。无论你是刚刚拿到录取通知书的萌新，还是已经在济大摸爬滚打的“老油条”，我们都希望这里的信息能帮你避开生活和学习中的“坑”，让你在济南大学的日子更加顺利。

这里涵盖了：

* **校园生活**：哪里的食堂最好吃？宿舍门禁几点？快递点怎么找？
* **学业办事**：图书馆怎么预约？教务系统选课有什么技巧？
* **交通出行**：校车时刻表、去各大火车站的最优路线。

## 🤝 贡献指南

校园的信息是不断更新的，个人的力量有限，**“校园通”需要大家的共同维护**！

如果你发现本站的信息有误、有遗漏，或者你有一些独家的“干货”想要分享，非常欢迎你参与贡献。本站基于 Markdown 编写，即使你没有编程基础也能轻松上手。

**如何贡献：**

1. 访问本站右上角的 **GitHub 仓库**。
2. 找到对应的 `.md` 文档，点击右上角的 ✏️ (Edit) 按钮直接修改。
3. 提交一个 Pull Request (PR)，管理员审核通过后你的名字就会留在贡献者名单里！
